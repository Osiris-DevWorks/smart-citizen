# Smart Citizen 2.4.0

> ⚠️ **If Windows blocks the installer:** Smart Citizen isn't code-signed yet, so Windows 11's **Smart App Control** blocks it (Unblock in Properties doesn't help). Go to **Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings**, set it to **Off**, run `SmartCitizen-2.4.0-Setup.exe`, then turn it back on if you like.

**Download:** [latest release](https://github.com/Osiris-DevWorks/smart-citizen/releases/latest). `SmartCitizen-2.4.0-Setup.exe` is the installer; `SmartCitizen-Portable-v2.4.0.zip` runs without installing (and [on Linux through Wine](https://github.com/Osiris-DevWorks/smart-citizen/blob/main/docs/LINUX.md)). Existing installs will offer the update at launch.

## New languages

- **Turkish** and **Traditional Chinese**: pick them on the Config tab. Turkish uses the game's `polish_(poland)` slot.
- **Korean** is bring-your-own-file (its license forbids bundling). Install the community patch, copy its `global.ini` outside your Star Citizen folder, and point **Map Language File → Browse...** at the copy.

## New

- **Verify Install Location** (Config tab) shows which install the RSI Launcher starts, flags duplicates and folders with no `Data.p4k`, and switches installs in one click.
- **First run** finds installs in custom folders from the launcher's log.
- **Blueprint auto-scan** on startup, opt-in, with an optional popup for new finds.
- **Uninstaller option** to delete all saved settings. Off by default, and it never touches your Star Citizen install or anything outside Smart Citizen's own folders.

## Fixes

- The Apply button starts green when nothing changed, stays red after a failed apply, goes red after a language switch, and works in Simple mode.
- Apply Preview counts now match the Apply dialog, and a fresh Simple-mode apply no longer reports 0 enhancements.
- Blueprint scans read only LIVE and HOTFIX, never the test servers. The keyword search now sits under the filters.
- DataForge extraction now uses about 2 GB of temporary space next to your DataForge cache folder instead of in `%TEMP%`. When your cache is on another drive, this prevents the system drive from being used and possibly running out of space due to caching.
- Esc or X stops an extraction (DataForge or global.ini). Closing the app stops it too, and your previous data is kept.
- Generate Enhancements no longer crashes with a single category ticked.
- Installing into a non-empty folder creates a `Smart Citizen` subfolder, and Setup only removes its own files.
- The installer recognises work/school OneDrive and keeps pre-0.9 OneDrive data on upgrade.
- Auto-update never stalls on a message box and relaunches cleanly.
- Export Settings includes default values, so imports restore exactly what you exported.
- A folder without game data is never saved as your install path.

**After updating:** run **Generate Enhancements**, then **Apply Enhancements**.
