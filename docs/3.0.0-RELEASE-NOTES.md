# Smart Citizen 3.0.0

> ⚠️ **If Windows blocks the installer:** Smart Citizen isn't code-signed yet, so Windows 11's **Smart App Control** blocks it (Unblock in Properties doesn't help). Go to **Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings**, set it to **Off**, run `SmartCitizen-3.0.0-Setup.exe`, then turn it back on if you like.

**Download:** [latest release](https://github.com/Osiris-DevWorks/smart-citizen/releases/latest). `SmartCitizen-3.0.0-Setup.exe` is the installer; `SmartCitizen-Portable-v3.0.0.zip` runs without installing (and [on Linux through Wine](https://github.com/Osiris-DevWorks/smart-citizen/blob/main/docs/LINUX.md)). Existing installs will offer the update at launch.

## Smart Citizen Overlay

A new **Overlay** tab starts optional windows over the game (run Star Citizen borderless windowed).

- **Mining scan decoder:** reads the scan signature under your radar and shows what's there, e.g. `3 × Lindinium`. Works for ship, ROC and hand mining, and salvage.
- **Alerts:** tick minerals (or Salvage) to watch. A watched scan can glow, flash, turn green, grow or play a sound: the Smart Citizen chime, a spoken alert (10 voices) or a Windows sound, with a Preview button.
- **Drawer:** a side panel, with its own hotkey, to search your blueprints and tick the ones you own, find where minerals are by star system, and see which items a mineral crafts into.
- **Mark new blueprints as owned:** while the overlay runs, blueprints you receive in game are marked owned (LIVE and HOTFIX).
- It only reads the screen and `Game.log`. It never touches the game's memory or sends input.

## New

- **Russian:** pick it on the Config tab. It uses the game's Korean slot (the only in-game font with Cyrillic), so applying Russian replaces Korean and the other way round.
- **Armor weight tags:** the Tag Builder's new Armor tab adds `[L]`, `[M]`, `[H]` and more to armor names.
- **Font size:** Small, Medium or Large on the Config tab, after a restart.
- **Run in Background:** press Esc during an extraction or a generation and keep working. Settings it depends on lock until it ends.
- **Starter blueprints:** the P4-AR, S-38, their magazines and the Field Recon Suit are owned after your next blueprint scan.
- **Clear Shader Cache:** a new Star Citizen Tools box on the Config tab cleans or removes the game's shader cache folders, one game build at a time.
- **Faster extraction:** DataForge extraction is about three times faster, and generating enhancements about twice as fast.

## Fixes

- Switching language updates the Help panel and every label at once, no restart needed.
- Other languages no longer fall back to English after a global.ini extraction, a channel switch or a data folder change.
- A value you cleared no longer comes back after a reload, and Reset user.ini can be undone with Restore user.ini.
- Ticked enhancement categories count for Generate and Apply without the small Apply button.
- The extraction progress bar keeps moving instead of looking frozen.
- Extraction checks free space first, refuses a cache folder that is a link, and stops at once when Windows refuses a folder.
- Extraction waits while the RSI Launcher is patching or verifying `Data.p4k`.
- Closing during Generate Enhancements no longer leaves a half-built set; the next start offers to regenerate.
- Clear Cache finds the DataForge cache in its real folder.
- After a global.ini extraction, Smart Citizen asks when the DataForge cache is out of date.
- Answering YES to the installer's OneDrive warning now moves your data.
- The blueprint scan no longer leaves "Finishing up…" in the status bar.

**After updating:** run **Generate Enhancements**, then **Apply Enhancements**. The first Generate takes a minute or two while Smart Citizen re-reads the game's item data. Later runs take seconds.
