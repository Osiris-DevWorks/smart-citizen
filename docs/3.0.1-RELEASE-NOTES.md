# Smart Citizen 3.0.1

> ⚠️ **If Windows blocks the installer:** Smart Citizen isn't code-signed yet, so Windows 11's **Smart App Control** blocks it (Unblock in Properties doesn't help). Go to **Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings**, set it to **Off**, run `SmartCitizen-3.0.1-Setup.exe`, then turn it back on if you like.

**Download:** [latest release](https://github.com/Osiris-DevWorks/smart-citizen/releases/latest). `SmartCitizen-3.0.1-Setup.exe` is the installer; `SmartCitizen-Portable-v3.0.1.zip` runs without installing (and [on Linux through Wine](https://github.com/Osiris-DevWorks/smart-citizen/blob/main/docs/LINUX.md)). Existing installs will offer the update at launch.

## New

- **Play button reminder:** after Apply, the main menu's Play button reads "Run Smart Citizen after every patch" on a second line, so you know to update Smart Citizen when the game patches.
- **Guided tour:** updated for 3.0, with new steps for Settings Backup and Star Citizen Tools.

## Fixes

- **Blueprint scan in other languages:** Scan Logs for Owned Blueprints and the overlay's live watch now find blueprints when the game is in Spanish or another language, not only English.
- **Owned blueprints after a language switch:** the Owned list now follows the selected language. A blueprint no longer shows twice (once in English, once in your language), and old armour names are no longer saved as set names like "Dust Devil".
- **Overlay scan decoder:** reads the scan number at a wide field of view, in small cockpits, on bright planets and snow, and with Windows HDR on.
- **Gem rocks:** Aphorite, Dolivine and Hadanite rocks get their [CF] tag before you fracture them.
- **Carrack map:** room labels no longer show ship stats.
- **Linux:** the overlay needs an X11 session, not Wayland (see the Linux guide).

**After updating:** run **Generate Enhancements**, then **Apply Enhancements**.
