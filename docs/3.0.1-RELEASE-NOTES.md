# Smart Citizen 3.0.1

> ⚠️ **If Windows blocks the installer:** Smart Citizen isn't code-signed yet, so Windows 11's **Smart App Control** blocks it (Unblock in Properties doesn't help). Go to **Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings**, set it to **Off**, run `SmartCitizen-3.0.1-Setup.exe`, then turn it back on if you like.

**Download:** [latest release](https://github.com/Osiris-DevWorks/smart-citizen/releases/latest). `SmartCitizen-3.0.1-Setup.exe` is the installer; `SmartCitizen-Portable-v3.0.1.zip` runs without installing (and [on Linux through Wine](https://github.com/Osiris-DevWorks/smart-citizen/blob/main/docs/LINUX.md)). Existing installs will offer the update at launch.

## Highlights

### Mining scan decoder

- Reads the scan signature at a wide field of view, in small cockpits, on bright planets and snow, and with Windows HDR on.

### Smart Citizen Overlay

- Firing while you aim no longer clicks the drawer and takes focus away from the game.
- Closing the drawer with its tab gives the mouse and keyboard back to the game, like the hotkey does.
- The drawer hotkey no longer sees your other key presses. In game, it only checks its own keys.

## New

- **Play button reminder:** after Apply, the main menu's Play button says "Run Smart Citizen after every patch".
- **Guided tour:** updated for 3.0, with steps for Settings Backup and Star Citizen Tools.

## Fixes

- The blueprint scan and the overlay find blueprints when the game is in Spanish or another language.
- The Owned list follows your language. A blueprint no longer shows twice, and old armor names no longer turn into set names like "Dust Devil".
- Aphorite, Dolivine and Hadanite rocks get their [CF] tag before you fracture them.
- Carrack map room labels no longer show ship stats.
- Linux: the overlay needs an X11 session, not Wayland (see the Linux guide).

**After updating:** run **Generate Enhancements**, then **Apply Enhancements**.
