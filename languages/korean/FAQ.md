# 자주 묻는 질문

가장 많이 받는 질문에 대한 빠른 답변입니다. 여기 없는 질문이 있다면 하단의 **피드백** 링크를 클릭해 Discord에서 물어보세요.

## Smart Citizen이 적용한 변경 사항을 어떻게 되돌리나요?

쉽습니다. 언제든지 가능합니다. Smart Citizen은 게임의 원본 파일을 직접 수정하지 않으므로, 원본으로 돌아가는 것은 클릭 한 번이면 됩니다:

- **도구 모음 → 더 보기 → 현지화 지우기**는 Smart Citizen이 작성한 사용자 지정 `global.ini`를 삭제합니다. 게임은 즉시 내장 텍스트로 돌아갑니다. 편집 내용은 사라지지 않고 앱에 계속 저장되어 있으며, 언제든지 다시 적용할 수 있습니다.
- 완전히 되돌리는 대신 한 버전만 되돌리고 싶으신가요? **도구 모음 → 더 보기 → 백업 복원**은 게임 파일을 타임스탬프가 찍힌 백업으로 되돌립니다(Smart Citizen은 최근 5개를 유지하며, 적용할 때마다 새로 만듭니다).

개인 편집 내용은 게임과 별개로 Smart Citizen 데이터 폴더의 `user.ini`에 저장되므로, 게임 파일을 지워도 편집 내용에는 영향이 없습니다.

## Smart Citizen을 사용하면 정지당하나요?

Smart Citizen은 현지화 텍스트(게임이 보여주는 단어)만 편집할 뿐, 게임 로직에는 손대지 않고, 어떤 이점도 주지 않으며, CIG 서버와 통신하지 않습니다. 저희의 변경 사항은 **문제없어야** 합니다.

CIG는 커뮤니티 현지화를 공개적으로 지지해 왔습니다. [Community Localization Update](https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/star-citizen-community-localization-update) 게시물은 플레이어가 만든 번역에 대한 공식 지원을 명시하고 있으며, 저희는 이것이 Smart Citizen이 수행하는 방식의 현지화 편집을 명시적으로 허용하는 것으로 이해하고 있습니다.

인지도 높은 스트리머들도 비슷한 현지화 프로젝트를 공개적으로 운영하고 있으며, 중단하라는 요청을 받은 사례는 없습니다.

다만, Smart Citizen을 사용하는 방식은 본인의 책임입니다. 저희의 변경 사항은 문제없어야 하지만, 본인이 직접 수행하는 모든 행위에 대해서는 본인과 관련자가 발생할 수 있는 손해에 대한 책임을 집니다. 어떤 변경이 적절한지 확신이 서지 않는다면, 외형적인 변경으로만 유지하고 백업을 보관하세요.

## Smart Citizen은 어떤 파일을 수정하나요?

단 하나뿐이며, **강화 적용**을 클릭했을 때만 수정됩니다:

- `StarCitizen\<채널>\data\Localization\<언어>\global.ini` — 선택한 채널(LIVE, PTU 등)과 언어에 대한 게임의 현지화 파일입니다. Smart Citizen은 먼저 기존 파일을 백업한 후 병합된 결과를 씁니다.
- 또한 게임이 올바른 현지화를 불러오도록 `user.cfg`에 `g_language`가 설정되어 있는지 확인합니다. 게임 설치본의 다른 어떤 것도 변경되지 않습니다.

Smart Citizen이 자체 용도로 생성하는 모든 것(소스 캐시, 강화 파일, 백업, `user.ini`)은 게임이 아니라 Smart Citizen 데이터 폴더에 저장됩니다.

## Windows는 왜 이 앱을 인식할 수 없다고 하나요?

Smart Citizen이 아직 코드 서명이 되어 있지 않기 때문입니다. Windows SmartScreen과 Smart App Control은 완전히 안전한 앱이라도 서명 인증서 정보가 등록되어 있지 않은 배포자의 새 앱을 표시합니다. 이는 "이전에 본 적 없음" 경고이지 "위험함" 경고가 아닙니다.

실행하려면: SmartScreen 프롬프트에서 **추가 정보 → 실행**을 클릭하세요. Smart App Control이 완전히 차단하고 있다면 해당 프롬프트에서 앱을 허용하거나, 일시적으로 Smart App Control을 끄고 설치한 후 다시 켤 수 있습니다.

코드 서명은 저희 로드맵에 있으며, 이 경고를 없앨 예정입니다. 그때까지는 정품 빌드임을 확인할 수 있도록 Smart Citizen을 공식 GitHub 릴리스에서만 다운로드하세요.
