# Smart Citizen — 빠른 시작 가이드

## 최초 설정

Smart Citizen은 실행 시 이전 세션의 사용자 지정 내용을 다시 불러오고 Star Citizen 설치를 확인합니다. 설치 프로그램이 이 경로를 미리 채워 두지만 **설정** 탭에서 변경할 수 있습니다. 모든 기본 현지화와 DataForge 데이터는 **설치된 `Data.p4k`에서 직접** 가져옵니다(다운로드도, 커뮤니티 미러도 없음). 따라서 설치 후 또는 게임 패치 후에는 반드시 한 번 추출을 진행해야 합니다.

## 간단 모드와 고급 모드

Smart Citizen은 두 모드 중 하나로 열리며, 언제든지 전환할 수 있습니다.

- **간단 모드**는 버튼 두 개짜리 화면입니다: **강화 적용** 버튼 하나는 현재 설정으로 전체 과정(추출, 생성, 적용, 먼저 게임 파일 백업)을 실행하고, 다른 버튼은 **고급 모드**로 전환합니다. 텍스트를 직접 편집할 필요 없이 그냥 강화 내용만 적용하고 싶을 때 빠른 경로입니다.
- **고급 모드**는 전체 앱입니다: 텍스트 테이블, 필터, 강화 탭, 설정 탭, 그리고 이 가이드의 나머지 모든 내용입니다.

설치 시 기본 모드를 선택하거나, 앱 안에서 언제든지 전환할 수 있습니다. 간단 모드는 고급 모드에서 마지막으로 저장한 설정을 사용합니다.

## 1. Data.p4k에서 기본 현지화 추출하기

**설정** 탭을 열고 **Data.p4k에서 추출**을 클릭하세요. 이렇게 하면 기본 `global.ini`와 강화 생성기가 사용하는 DataForge 엔터티 XML(함선, 부품, 무기, 임무, 설계도 등)이 압축 해제됩니다.

추출이 완료되면 추출된 `base.ini`가 강화 파일과 저장된 `user.ini` 재정의 내용과 병합되어 테이블에 자동으로 로드됩니다.

## 2. 현지화 텍스트 편집하기

- 텍스트를 편집하려면 아무 **사용자 지정 값** 셀을 더블클릭하세요.
- **기본값** — `Data.p4k`에서 추출한 `base.ini`의 원본 텍스트입니다.
- **현재 값** — 재정의 전 유효 값입니다(기본 + 가져온 INI 레이어).
- **사용자 지정 값** — 개인 편집 내용입니다. 변경할 때마다 자동으로 저장되며 `<데이터 폴더>\<채널>\user.ini`에 저장됩니다(데이터 폴더는 기본적으로 `Documents\Smart Citizen`이며, 각 Star Citizen 채널 — LIVE, PTU, EPTU, HOTFIX, TECH-PREVIEW — 은 독립된 재정의 내용을 가집니다).
- **상태** 열은 각 행의 현재 값이 어디서 왔는지 표시합니다:
  - **수정됨** — 사용자 지정 값을 직접 편집했습니다.
  - **강화됨** — 강화 파이프라인(통계 오버레이, 설계도 태그 등)에 의해 자동 생성되었습니다.
  - **수정되지 않음** — `base.ini`의 기본 텍스트입니다.
  - **신규** — 기본 `base.ini`가 아닌 재정의 내용이나 강화 파이프라인에만 존재하는 키입니다.
- 두 열 제목 사이의 구분선을 드래그해 **모든 열의 크기를 조절**할 수 있으며, 구분선을 더블클릭하면 표시된 내용 중 가장 넓은 것에 맞춰 열이 조정됩니다. 열 너비는 재시작 후에도 유지됩니다. 직접 크기를 조절하기 전까지는 Smart Citizen이 열을 창에 맞게 자동으로 맞추므로, 새로 설치했을 때도 화면에 알맞게 열립니다. 이 자동 레이아웃으로 되돌리려면 **창 비율 재설정**을 사용하세요(아래 참조).

## 3. 미리보기 패널

오른쪽 상단의 **미리보기 패널**은 현재 선택된 행의 렌더링된 텍스트를 표시합니다. 게임의 현지화 토큰이 스타일이 적용된 HTML로 변환되어, 텍스트가 게임 내에서 대략 어떻게 보일지 알 수 있습니다:

- `\n` → 줄바꿈
- `<EM3>...</EM3>` → 밑줄 처리된 섹션 제목
- `<EM4>...</EM4>` → 굵은 파란색 인라인 강조(주로 통계 값)
- `~mission(이름)` → 회색으로 표시된 `[이름]` 자리표시자(게임이 실행 시 실제 값으로 대체)

이 패널은 모든 탭에서 계속 표시되며 **텍스트 편집기**에서 마지막으로 선택한 행을 반영합니다. 적용하기 전에 긴 임무 설명이나 저널 항목이 어떻게 포맷될지 확인하는 데 유용합니다.

## 4. 카테고리

**카테고리** 필터를 사용해 특정 영역에 집중하세요:

- **함선** — 함선 이름과 설명(`vehicle_Name*`, `vehicle_Desc*`, Wikelo/Collector 모드 포함).
- **함선 부품** — 실드, 발전기, 냉각기, 퀀텀 드라이브, 점프 드라이브, 함선 무기, 미사일, 폭탄, 터렛.
- **임무** — 임무 브리핑, 계약 텍스트, 보상 설명.
- **장비** — FPS 무기, 방어구, 헬멧, 슈트, 조준경.
- **교역품** — 거래 상품 및 제작 재료.
- **저널** — 게임 내 저널/Galactapedia 스타일 항목.
- **기타** — 그 외 모든 것.

## 5. 검색 및 필터링

- **검색 상자**를 사용해 키나 텍스트 내용으로 텍스트를 찾으세요.
- **카테고리** 및 **상태**(수정됨 / 강화됨 / 수정되지 않음 / 신규) 필터와 조합하세요.
- 본인의 편집 내용만 보려면 **수정되지 않은 항목 숨기기**를 선택하세요.
- 각 제목 아래의 **열별 필터 상자**로 테이블 안에서 더 좁혀서 검색할 수 있습니다.
- 아무 열 제목을 클릭하면 해당 열 기준으로 정렬됩니다. **★** 제목을 클릭하면 즐겨찾기를 맨 위로 정렬합니다.

## 6. 함선 즐겨찾기

- 아무 함선 행에서 **★** 열을 클릭해 즐겨찾기로 표시하세요. 함선의 이름 행만 즐겨찾기할 수 있습니다. 동일 함선의 설명 행은 게임 내에서 대응되는 동작이 없으므로, 그곳의 별표와 정렬 순서 열은 비어 있습니다.
- 즐겨찾기한 함선은 게임 내 함선 목록 맨 위에 정렬되도록 이름 앞에 설정 가능한 접두사가 붙습니다.
- **강화** 탭에서 접두사 문자를 변경하세요(기본값: `*`).
- 함선 설명과 다른 모든 카테고리를 숨기고 함선/차량 이름 행만 표시하려면 검색 및 필터 행에서 **함선/차량 이름만**을 선택하세요. **즐겨찾기만**과 함께 사용하면 즐겨찾기할 수 있는 행만 정확히 볼 수 있습니다.

## 7. 게임에 변경 사항 적용하기

편집 내용을 게임 설치 폴더에 기록하려면 **강화 적용**을 클릭하세요. 무언가를 덮어쓰기 전에 현재 `global.ini`의 타임스탬프가 찍힌 백업이 `<데이터 폴더>\<채널>\backups\`에 생성됩니다.

버튼 색상이 현재 상태를 알려줍니다: **빨간색**은 마지막 적용 이후 무언가(편집, 재생성, 언어 또는 채널 전환)가 변경되었지만 아직 게임에 반영되지 않았음을 의미합니다. **초록색**은 게임이 이미 불러온 내용과 일치함을 의미하며, 다시 할 작업이 없으므로 버튼이 비활성화됩니다. 강화 탭의 **강화 생성**과 **태그 변경 저장**에도 동일한 빨간색/초록색 규칙이 적용됩니다. 적용 버튼이 여전히 빨간색인 상태로 앱을 닫으면, Smart Citizen이 지금 적용할지 적용하지 않고 종료할지 물어봅니다. 그래서 적용되지 않은 작업이 조용히 사라지는 일이 없습니다.

Smart Citizen은 또한 런처 버전 문자열(`Frontend_PU_Version`)에 작은 워터마크를 남깁니다. 자체 줄에 `\nLocalizations Enhanced with Smart Citizen v{VERSION}`을 추가합니다. 이를 통해 현지화 패키지가 활성화되어 있는지 게임 내에서 확인할 수 있습니다. Star Citizen 메인 메뉴의 버전 레이블을 보세요. 이 워터마크는 적용할 때마다 다시 작성되므로 버전이 바뀌어도 계속 쌓이지 않습니다.

## 8. 백업 복원하기

이전 버전으로 되돌리려면 도구 모음의 **더 보기** 메뉴를 열고 **백업 복원**을 선택하세요. Smart Citizen은 최대 **5개의 자동 백업**을 유지하며, 새 백업이 생성될 때마다 가장 오래된 것이 삭제됩니다.

## 9. 현지화 지우기

게임 디렉터리에서 사용자 지정 `global.ini`를 삭제하여 게임을 기본(원본) 텍스트로 되돌리려면 **더 보기** 메뉴를 열고 **현지화 지우기**를 선택하세요. `<데이터 폴더>\<채널>\user.ini`에 저장된 재정의 내용은 그대로 남아 있으며 언제든지 다시 적용할 수 있습니다.

## 10. INI 가져오기

기존 INI 파일을 재정의 내용에 병합하려면 **설정** 탭의 **INI 가져오기**를 사용하세요(도구 모음의 **더 보기** 메뉴에서도 사용 가능). 충돌 해결 대화 상자에서 키별로 **현재 값 유지**, **가져온 값 사용**, **뒤에 추가**, **앞에 추가**, 또는 **사용자 지정** 값 제공 중 하나를 선택할 수 있습니다.

## 11. 현지화 패키지 내보내기

현재 적용된 `global.ini`를 하나의 zip 파일 — `SmartCitizen-LocPack-{channel}-{YYYYMMDD}.zip` — 로 묶으려면 **더 보기** 메뉴를 열고 **INI 내보내기…**를 선택하세요. 다른 사람이 이 파일을 `StarCitizen\<채널>\data\Localization\english\`에 넣기만 하면 Smart Citizen을 설치하지 않고도 동일한 현지화 패키지를 사용할 수 있습니다. 친구나 소속 그룹과 프리셋을 공유할 때 유용합니다.

## 12. user.ini 재설정하기

활성 채널의 모든 개인 편집 내용을 지우려면 **설정** 탭의 **user.ini 재설정**을 사용하세요. 확인 프롬프트가 표시되어 실수로 클릭한 것이 아닌지 확인하며, 현재 `user.ini`의 자동 백업이 먼저 `<데이터 폴더>\<채널>\backups\`에 저장됩니다. 그래서 마음이 바뀌면 재설정을 되돌릴 수 있습니다.

## 13. 설정 내보내기/가져오기

전체 Smart Citizen 설정을 PC 간에 옮기거나 새로 설치하기 전에 백업하려면 **설정** 탭의 **설정 내보내기…**와 **설정 가져오기…**를 사용하세요. 내보내기는 앱 설정과 모든 채널의 `user.ini` 재정의 내용을 Star Citizen 설치 경로와 함께 하나의 작은 zip으로 묶습니다. 다른 PC에서 의미가 없는 컴퓨터별 경로와 레이아웃(데이터 폴더, 캐시 위치, 창 크기, 텍스트 편집기 열 너비)은 제외됩니다. 가져오기는 이 백업을 현재 설정 위에 겹치고 포함된 채널의 `user.ini`를 교체합니다. 현재 `user.ini` 파일은 먼저 **user.ini 복원**을 통해 스냅샷이 저장되므로, 가져오기는 되돌릴 수 있습니다. Star Citizen 경로는 가져오는 PC에 여전히 존재할 때만 유지되며, 그렇지 않으면 Smart Citizen이 대신 자동으로 감지합니다. 가져온 설정을 불러오기 위해 Smart Citizen이 다시 시작되며, 이후 강화를 재생성하고 적용할지 물어봅니다.

## 14. 게임 업데이트 후

Star Citizen이 업데이트되면 편집 내용은 `<데이터 폴더>\<채널>\user.ini`에 그대로 보존됩니다. 패치된 게임에서 새 기본 텍스트를 가져오려면 **Data.p4k에서 추출**을 다시 실행하세요. 테이블이 자동으로 다시 로드되고 사용자 지정 내용이 그 위에 다시 적용됩니다.

## 15. 언어 전환하기

**설정** 탭의 **언어** 드롭다운(채널 옆)에서 언어를 선택하세요. 전환하면 앱의 인터페이스와 테이블의 게임 텍스트가 모두 변경됩니다:

- **영어**(기본값)는 본인의 `Data.p4k`에서 추출한 기본 텍스트를 사용합니다.
- **다른 언어**는 해당 언어의 커뮤니티 번역 `global.ini`를 사용하며, 영어 기본 텍스트 위에 겹쳐 적용됩니다. 번역이 다루지 않는 텍스트는 사라지지 않고 영어로 대체됩니다. 언어의 소스가 URL이면 언어별로 캐시되며, 이후 다시 전환할 때는 캐시를 재사용합니다. 소스가 로컬 파일이면 매번 새로 복사됩니다.
- **강화는 영어로 유지됩니다.** 통계 블록, 태그, 임무 세부 정보는 게임 데이터에서 생성되며 번역된 본문 위에서 영어 형태를 유지합니다. 혼합된 줄(예: 영어 통계 블록 안의 다른 언어 역할 이름)이 나타날 수 있으며, 이는 버그가 아니라 예상된 동작입니다.
- **언어 파일 매핑**(설정 탭)을 사용하면 한 언어를 다른 `global.ini` URL이나 로컬 파일로 지정할 수 있습니다. 예를 들어 커뮤니티 번역의 자체 포크나, 라이선스 제약으로 공개 URL이 없는 언어를 위해 본인이 직접 구한 파일을 지정할 수 있습니다. 여기서 지정한 값은 번들에 포함된 기본값보다 우선합니다.
- 일부 인터페이스 텍스트는 앱을 다시 시작해야 업데이트됩니다. 테이블 텍스트는 즉시 다시 로드됩니다.

적용하면 게임 설치 폴더 안의 해당 언어 폴더에 기록되고 `user.cfg`의 `g_language`가 설정되어, 게임이 올바른 파일을 불러옵니다.

번역을 돕고 싶으신가요? 언어별 번역 상태는 저장소의 `languages/TRANSLATIONS.md`에서 추적됩니다. 저희는 기계 번역보다 여러분의 번역을 훨씬 반깁니다. Discord로 연락 주세요.

## 16. 앱 업데이트

Smart Citizen은 시작할 때마다 새 버전이 있는지 확인합니다. 새 버전이 있으면 스크롤 가능한 창에 릴리스 노트가 표시되며 두 가지 선택지가 있습니다:

- **지금 업데이트**는 새 설치 프로그램을 다운로드하고, Windows가 권한을 요청하며, Smart Citizen이 종료되고, 업데이트한 후 새 버전으로 다시 열립니다. 편집 내용, 백업, 설정은 그대로 유지됩니다.
- **나중에**는 현재 버전을 유지하며, 다음 실행 시 다시 물어봅니다.

**설정** 탭의 **업데이트 확인**으로 언제든지 수동으로 확인할 수도 있습니다. 휴대용 버전은 실행할 설치 프로그램이 없으므로 대신 **릴리스 페이지 열기** 버튼을 표시합니다: 새 zip을 다운로드해 이전 폴더 위에 압축을 풉니다.

## 강화 탭

- SCM 속도, 실드 HP, DPS, 화물 용량, 채굴 레이저 빔 통계(파쇄/추출), 휴대용 인양 도구 속도, 설계도 풀, 임무 경험치 등 설명에 숫자 통계를 추가하는 오버레이를 켜고 끕니다. 임무 경험치는 그 경험치가 어느 평판 트랙에 반영되는지도 표시하며(예: `750 XP (Hauling)`), Battaglia 스캔/채굴 계약은 대상 광석의 기본 자원 신호가 포함된 `[RS ####]` 태그를 가지며, 채굴 개론서 저널은 각 광석의 기본 RS를 채굴 위치 옆에 나열합니다.
- **의료 소모품** — 기본 CureLife 펜(MedPen, OxyPen, AdrenaPen 등)에 쉬운 효과 설명 줄을 추가하여, 설명이 배경 설정뿐 아니라 그 펜이 실제로 무엇을 하는지 알려줍니다.
- **설명 위에 통계 표시** — 통계 블록을 설명 아래가 아니라 위에 배치하여, 게임 내에서 가장 먼저 보이는 것이 숫자가 되도록 합니다.
- **광석 이름 옆에 자원 신호(RS) 표시** — 채굴 가능한 각 광석의 기본 자원 신호를 표시 이름에 추가합니다(예: "Aluminium (RS 4285)"). 이렇게 하면 임무 추적기를 포함해 게임이 해당 이름을 표시하는 모든 곳에 나타납니다. 아래 임무 세부 정보 필드의 자원 신호 줄과는 독립적입니다.
- 각 강화 카테고리를 독립적으로 활성화하거나 비활성화합니다.
- 함선 즐겨찾기 접두사 문자를 구성합니다.
- **설계도 소유 여부**는 자체 **설계도 추적기** 탭으로 이동했습니다. 다음 섹션을 참조하세요.
- **태그 빌더** — 부품, 미사일, 함선 무기, 상품 이름에 붙는 괄호 태그를 사용자 지정합니다. ▲/▼로 요소 순서를 바꾸고, 개별 요소를 켜거나 끄고, 약자 길이(`M` / `MIL` / `Military`)를 바꾸고, 구분 기호(없음, 하이픈, 공백 등)와 괄호(대괄호, 소괄호, 없음 등)를 선택하고, 태그가 이름 앞이나 뒤에 나타나도록 선택할 수 있습니다. 부품에는 선택적인 **유형** 요소(실드, 냉각기, 발전기 등)도 있으며 기본적으로 비활성화되어 있습니다. 상품에는 **레이블**, **용도**(상품의 제작 재료가 무엇에 쓰이는지), **컬렉션** 요소가 있으며 모두 기본적으로 비활성화되어 있습니다. 태그 빌더에서 원하는 것을 활성화하세요. 저장하고 재생성하려면 **태그 변경 저장**을 클릭하세요. (**강화 생성**도 먼저 대기 중인 태그 편집 내용을 저장하므로, 저장하지 않은 조정 사항이 재생성 시 빠지지 않습니다.)
- **임무 제목**(태그 빌더 탭) — 운송 임무 제목을 경로로 시작하게 합니다. 배치(앞에 추가, 뒤에 추가, 또는 제목 대체), 경로 화살표(`>`, `->`, `to`, 또는 각 방향의 단일/다중 종점을 표시하는 모양 부호 `->-`/`->=`/`=>-`/`=>=`), 제목 구분 기호, 위치를 얼마나 표시할지(기본값은 전체 주소이며, 일부 드문 임무에서는 짧은 이름이 표시되지 않을 수 있음)를 실시간 미리보기와 함께 선택하세요. 운송 작업은 `Area18 > Lorville - <원래 제목>`처럼 표시되어 계약 목록에서 작업을 한눈에 알 수 있으며, 다중 정차 운송은 하차 지점을 나열합니다(`Area18 > Lorville, New Babbage`). 두 개의 독립된 옵션이 기본 제목을 다듬습니다: **원래 제목 줄이기**는 정해진 문구 축약을 적용하고(예: "Opportunity for Independent Cargo Hauler" → "Intro", "Local Shipment Route" → "Route", Ling Family 및 등급 접두사 처리 포함), **화물 크기 줄이기**는 화물 등급 크기를 약자로 표시합니다("Extra Small" → "XS"). 개별 체크박스로 더 세밀하게 조정할 수 있습니다. "Cargo"나 "Haul"을 완전히 제거하거나, "Rank"를 생략하거나, 강조를 위해 "Direct" 운송에 밑줄을 표시할 수 있어 긴 제목에도 경로와 태그가 들어갈 수 있습니다. 같은 페이지의 **일반 태그** 체크박스는 제목에만 표시되는 태그를 켜거나 끕니다: 평판 보상, 설계도 태그, `[ACE]`, Battaglia `[RS ####]` 태그, 평판 트랙 이름. 설계도 태그는 임무의 모든 버전이 설계도를 지급할 때 `[BP]`로 표시되고, 확실하지 않을 때(일부 버전만 지급하거나 게임 데이터가 확률적 지급으로 표시할 때)는 `[BP?]`로 표시됩니다.
- **임무 레이블** — 임무 강화 블록에 사용되는 섹션 제목(임무 세부 정보, 잠재적 설계도, 아이템 보상, 설계도 데이터), 특정 평판 등급이 없는 임무에 표시되는 경험치 레이블(기본값 "평판"), 제목에 사용되는 강조 태그(EM3 = 밑줄, EM4 = 색상)를 사용자 지정합니다.
- **임무 세부 정보 필드** — 임무 세부 정보 블록의 각 줄(임무 유형, 난이도, 적대 세력, 평판, 설계도, 에이스 파일럿, 자원 신호)을 개별적으로 표시하거나 숨겨, 임무 설명에 원하는 데이터만 담을 수 있습니다. **자원 신호**는 위의 임무 제목 `[RS ####]` 태그 및 광석 이름 주석과 별개로, Recco Battaglia 스캔/채굴 계약에 대상 광석별 전체 RS 값 변화를 나열하는 상세 내역을 추가합니다.
- `Data.p4k`에서 DataForge 데이터를 추출하고 강화 INI 파일을 재구성하려면 **강화 생성**을 클릭하세요. `patches/` 아래의 선언적 패치는 재생성할 때마다 멱등적으로 다시 적용되므로, 알려진 CIG 데이터 오류가 게임 패치를 기다리지 않고도 계속 수정된 상태로 유지됩니다.

## 설계도 추적기 탭

이미 보유한 제작 설계도를 추적하고, 게임 내에서 이것이 반영되는 것을 확인하세요: 보유한 항목은 임무의 잠재적 설계도 목록에 파란색 `[보유 중]` 태그가 붙어, 계약 목록만 봐도 아직 구해야 할 것이 무엇인지 한눈에 알 수 있습니다.

- **두 개의 목록, 하나의 이동 도구.** 왼쪽에는 사용 가능한 설계도, 오른쪽에는 보유한 설계도가 있습니다. 항목을 선택하고 화살표 버튼으로 이동하세요. 보유 목록은 재시작 후에도 유지됩니다.
- **빠르게 찾기.** 검색 상자로 두 목록을 좁힐 수 있고, **임무 / 유형 / 등급 / 크기 / 품급** 필터로 설계도가 어디서 드롭되는지, 어떤 종류의 아이템인지(방어구, 탄약, FPS 무기, 함선 부품 등)에 따라 사용 가능한 목록을 줄일 수 있습니다.
- **아무 설계도에 마우스를 올리면** 유형, 등급, 크기, 품급과 해당 설계도를 드롭할 수 있는 모든 임무가 한 줄씩 표시됩니다.
- **보유 설계도를 위해 로그 스캔**은 보유 목록을 자동으로 채웁니다: Star Citizen 로그 파일을 읽어 게임 내에서 받은 설계도를 찾아 보유로 표시합니다. 마지막 스캔 이후 받은 설계도만 가져오므로, 언제든지 다시 실행해도 부담이 없습니다. 스캔하려면 설정 탭에서 Star Citizen 설치 경로를 지정해야 합니다.
- **LIVE/HOTFIX도 함께 스캔(활성화되지 않은 쪽)**은 둘이 동일한 계정 진행 상황을 공유하므로, 현재 채널이 아닌 쪽도 설치되어 있으면 함께 확인합니다. LIVE에서 얻은 설계도는 HOTFIX 로그에도 나타나며 그 반대도 마찬가지입니다. 기본적으로 활성화되어 있습니다. PTU, EPTU, TECH-PREVIEW는 자체 진행 상황을 가진 별도의 테스트 빌드이며 이 옵션과 무관하게 스캔되지 않습니다.
- **모든 로그 다시 스캔(마지막 스캔 무시)**은 마지막 스캔 이후의 새 항목만 읽는 대신, 다음 스캔이 모든 로그 항목을 처음부터 다시 읽도록 강제합니다. 보유 목록이 잘못된 것 같고 일반 스캔으로 해결되지 않을 때 사용하세요. 스캔이 끝나면 자동으로 선택이 해제됩니다.
- **보유 설계도 내보내기… / 보유 설계도 가져오기…**는 보유 목록을 PC 간에 옮기거나 친구와 공유합니다. 내보내기는 보유한 모든 것을 JSON 또는 CSV 파일로 씁니다. 가져오기는 그 파일을 읽어 발견한 것을 추가하며, 이미 보유한 것은 절대 제거하지 않습니다. scmdb.net에서 내보낸 파일도 가져올 수 있습니다. 가져오기 요약에는 새로 추가된 설계도 수와, Smart Citizen이 추적하지 않는 파일 내 이름 목록이 표시됩니다.
- **보유 태그 적용**은 보유 목록을 변경한 후 불러온 텍스트에 `[보유 중]` 태그를 다시 반영합니다. 다른 작업 버튼과 마찬가지로, 보유 목록에 테이블이 아직 반영하지 않은 변경 사항이 있으면 **빨간색**, 모두 일치하면 **초록색**으로 표시됩니다.
- 텍스트 테이블의 **보유 중** 열은 여전히 별표를 표시하고 보유한 것을 우선 정렬하지만, 이제는 읽기 전용입니다. 소유 여부는 이 탭에서 관리됩니다.

## 설정 탭

- **모양** — 앱 테마를 선택합니다(아래 참조).
- **Star Citizen 설치** — LIVE 디렉터리의 경로입니다. 설치 시 자동으로 감지되며 여기서 편집할 수 있습니다. **채널** 드롭다운은 앱이 읽고 쓸 채널을 선택하고, **언어** 드롭다운은 앱과 게임 텍스트를 전환합니다(위의 *언어 전환하기* 참조).
- **Smart Citizen 데이터** — `user.ini`, 캐시, DataForge 추출, 생성된 강화 INI, 백업을 위한 폴더입니다. 기본값은 `Documents\Smart Citizen`이며, 추출이나 캐시 정리가 느리면 OneDrive 밖으로 옮기세요.
- **기본 현지화(P4K 추출)** — 설치된 게임에서 직접 기본 현지화와 DataForge 엔터티 데이터를 압축 해제하려면 **Data.p4k에서 추출**을 클릭하세요. 이는 기본 텍스트와 강화 데이터의 유일한 소스입니다.
- **INI 가져오기** — 충돌 해결 대화 상자를 통해 기존 INI 파일을 재정의 내용에 병합합니다.
- **user.ini 재설정** — 활성 채널의 모든 개인 편집 내용을 지웁니다. 확인을 요청하며 지우기 전에 현재 `user.ini`를 자동으로 백업합니다.
- **user.ini 복원** — 개인 편집 내용을 이전 스냅샷으로 되돌립니다. Smart Citizen은 `user.ini`의 회전 백업(최대 5개, 변경할 때마다 자동으로 생성)을 유지하므로, 가져오기나 편집이 잘못되면 이전 버전을 선택해 텍스트를 되찾을 수 있습니다. 복원 자체도 되돌릴 수 있습니다. 현재 파일은 먼저 스냅샷이 저장됩니다.
- **설정 내보내기… / 설정 가져오기…** — 전체 설정(설정과 모든 채널의 `user.ini`)을 하나의 작은 zip으로 백업하거나 새 PC에서 복원합니다. 위의 *설정 내보내기/가져오기*를 참조하세요.

## 창 레이아웃

Smart Citizen은 재시작 후에도 창 크기, 도킹된 텍스트 편집기의 레이아웃, 텍스트 편집기 열 너비를 기억합니다. 각 탭은 자체 내용을 스크롤하므로, 원하는 만큼 창을 작게 만들어도 컨트롤이 눌리거나 잘리지 않고 스크롤로 모든 것에 접근할 수 있습니다.

레이아웃이 애매한 상태가 되면(열이 얇게 눌려 있거나, 창 크기가 더 이상 화면에 맞지 않는 경우) **더 보기 → 창 비율 재설정**을 사용하세요. 창 크기, 패널 레이아웃, 열 너비를 기본값으로 복원합니다. 설정, 편집 내용, 현지화 데이터에는 영향을 주지 않습니다.

## 상태 표시줄

불러온/수정된 항목 수와 실행 중인 백그라운드 작업(추출, 생성, 적용)의 상태를 표시합니다.

## 가이드 투어

언제든지 도구 모음의 **튜토리얼** 버튼을 클릭하면 가이드 투어를 다시 볼 수 있습니다. 각 컨트롤을 가리키는 화면 안내와 함께 핵심 작업 흐름을 단계별로 안내합니다. 새 버전을 처음 실행할 때도 자동으로 실행되어, 새로 설치했을 때 막막하지 않습니다. 언제든지 **건너뛰기**를 눌러 닫을 수 있습니다.

## 자주 묻는 질문 탭

**자주 묻는 질문** 탭은 앱 안에서 가장 자주 받는 질문에 바로 답해줍니다: Smart Citizen이 어떤 파일을 건드리는지, 사용하면 정지당할 수 있는지, Windows가 왜 설치 프로그램에 경고를 표시하는지, 변경 사항을 어떻게 되돌리는지. 먼저 여기를 확인하세요. 질문이 다루어지지 않았다면 Discord가 클릭 한 번 거리에 있습니다.

## 키보드 단축키

- **Ctrl+Shift+C** — 필터링된 행을 클립보드에 복사합니다(키=값 형식).

## 문제 해결

- **테이블에 아무것도 없음** — **Data.p4k에서 추출**이 완료되고 추출 후 다시 불러오기가 끝났는지 확인한 다음, 파싱 오류가 있는지 **로그 탭**을 확인하세요.
- **강화가 비어 있거나 항목이 누락됨** — 강화 탭에서 **강화 생성**을 실행하세요. DataForge 캐시가 필요합니다(아직 하지 않았다면 먼저 **Data.p4k에서 추출**을 클릭하세요).
- **강화 적용이 실패함** — **설정 탭**에서 Star Citizen 설치 경로와 게임이 실행 중이 아닌지 확인하세요.
- **추출 시 Data.p4k가 잠겨 있다고 표시됨** — RSI Launcher가 업데이트를 다운로드하거나 검증하고 있습니다. 완료될 때까지 기다리거나(또는 런처를 닫고) **Data.p4k에서 추출**을 다시 클릭하세요.
- **게임 업데이트 후 데이터가 오래됨** — **Data.p4k에서 추출**을 다시 실행한 후 강화를 재생성하세요.

## 알려진 문제

일부 임무 텍스트 이상 현상은 Star Citizen 자체 데이터에서 비롯됩니다. 계약 레코드의 잘못된 현지화 키 참조나, 실제 표시 이름으로 연결되지 않는 설계도 보상 데이터가 그 예입니다. 게임은 계약과 설계도 보상을 실행 시 자체 `Data.p4k`에서 읽으므로, Smart Citizen은 이를 원본에서 고칠 수 없습니다. 생성하고 적용하는 *텍스트*만 수정할 수 있습니다. 가능한 경우, 게임 내 결과가 그래도 올바르게 표시되도록 데이터나 생성 단계에서 우회 처리합니다.

- **Jorrit Dossier — "Updated Power Usage Data"에 에너지 이상 텍스트가 표시됨** — CIG Issue Council [STARC-176797](https://issue-council.robertsspaceindustries.com/projects/STAR-CITIZEN/issues/STARC-176797). CIG의 `Hockrow_FacilityDelve_P2M4-Stanton4_Repeat` 계약은 `Description` 매개변수가 자신의 `P2M4_Repeat_desc`가 아니라 `@Hockrow_FacilityDelve_P2M1_Repeat_desc`를 가리키고 있어, 게임 내에서 플레이어는 "Power Usage Data"라는 제목의 임무에서 P2M1의 에너지 이상 관련 텍스트를 보게 됩니다. Smart Citizen은 두 단계로 이를 우회합니다. 둘 다 `patches/contracts/contractgenerator/mercenary_guild/hockrowagency/hockrowagency_facilitydelve.patch.json`에 선언되어 있습니다:
  1. 강화 생성기가 올바른 P2M4 설계도 풀(Corbel Smolder, Geist Rogue/Whiteout)을 P2M1의 것으로 축소하지 않고 `P2M4_Repeat_desc`에 붙이도록 하는 DataForge XML 편집.
  2. `P2M4_Repeat_desc`의 전체 내용(자체 텍스트와 자체 설계도 풀)을 라벨이 붙은 구분선과 함께 `P2M1_Repeat_desc`에 추가하는 현지화 텍스트 우회. 게임이 잘못된 포인터를 읽어 두 계약 모두에 대해 `P2M1_Repeat_desc`를 조회하므로, 이제 P2M4 계약은 의도된 내용을 표시합니다. P2M1 플레이어는 자신의 설명 뒤에 라벨이 붙은 부록으로 P2M4 블록을 보게 됩니다. 더 번잡하지만, 두 계약 모두 이제 올바른 설계도 풀과 올바른 텍스트를 표시합니다.

  CIG가 STARC-176797을 수정하면 이 패치 파일 전체를 삭제할 수 있으며, 다음 재생성 시 다시 깔끔하게 분리된 설명이 생성됩니다.

- **급유 임무가 임무의 잠재적 설계도 목록에서 깨진 노즐 이름을 표시함**(예: "Norfield" 대신 "Nozzle Fuelgiver Grin Nozzlefast"). 연료 노즐 설계도 보상은 다른 제작 가능 아이템과 달리 CIG 데이터에서 해결 가능한 엔터티 이름으로 연결되지 않아, 강화 생성기가 실제 제품 이름 대신 내부 파일 이름을 그대로 풀어놓은 형태로 대체하고 있었습니다. 알려진 8개 연료 노즐 변형(Marlin, Lindstrom, Bendix, Torrez, Ezra, Norfield, Harkin, RN-7s) 모두에 대해 `scripts/generate_enhancements_ini.py`의 알려진 이름 보정을 통해 수정되었습니다. 이미 본 임무에서 수정 사항을 적용하려면 **강화 생성**과 **게임에 적용**을 다시 실행하세요.
