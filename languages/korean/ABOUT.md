# Smart Citizen

*스타 시티즌을 위한 더 스마트한 텍스트*

## 이 프로젝트에 대하여

**Smart Citizen**은 Star Citizen 플레이어가 게임의 현지화 텍스트를 사용자 지정할 수 있는 강력하고 사용하기 쉬운 도구입니다. 완전한 지속성, 자동 백업, 게임 업데이트에 대한 원활한 지원과 함께 현지화 변경 사항을 불러오고, 편집하고, 적용하세요.

게임 커뮤니티를 위한 가치 있는 도구를 만드는 데 전념하는 1인 개발 스튜디오 **Osiris DevWorks**가 개발했습니다.

## Osiris DevWorks의 약속

모든 Osiris DevWorks 도구는 **완전 무료**이거나 **무료 등급**을 제공합니다. 결제 장벽이나 강제 구독 없이 게이머를 위한 가치를 창출한다는 것을 믿습니다.

### 후원자

프로젝트를 재정적으로 후원해 주신 분들께 감사드립니다. 여러분의 후원 덕분에 Smart Citizen을 모두에게 무료로 유지할 수 있습니다:

- **Dimwit the Wise**

Smart Citizen은 다음의 업스트림 도구도 함께 번들로 제공합니다:

- [**Osiris-DevWorks/odw-fast-unp4k**](https://github.com/Osiris-DevWorks/odw-fast-unp4k) — `Data.p4k`를 압축 해제하고 DataForge를 XML로 변환하는 데 사용되는 `unp4k.exe`와 `unforge.exe`입니다. 병렬 추출 및 기타 성능 개선을 더한, 원본 [**dolkensp/unp4k**](https://github.com/dolkensp/unp4k)의 포크입니다.

영어가 아닌 게임 텍스트는 커뮤니티 번역입니다:

- [**Dymerz/StarCitizen-Localization**](https://github.com/Dymerz/StarCitizen-Localization) — 프랑스어, 브라질 포르투갈어, 이탈리아어 언어 옵션을 지원하는 커뮤니티 유지 관리 `global.ini` 번역입니다. 실제 작업은 그들의 번역가들이 하며, 저희는 그저 전달할 뿐입니다.
- [**Thord82/Star_citizen_ES**](https://github.com/Thord82/Star_citizen_ES): 스페인어 언어 옵션을 지원하는 커뮤니티 유지 관리 `global.ini` 번역입니다.
- [**stdblue/StarCitizenJapaneseResources**](https://github.com/stdblue/StarCitizenJapaneseResources): 일본어 언어 옵션을 지원하는 커뮤니티 유지 관리 `global.ini` 번역입니다.
- [**42Kit**](https://ini.42kit.com/): 중국어 언어 옵션을 지원하는 커뮤니티 유지 관리 `global.ini` 번역입니다.
- [**rjcncpt/StarCitizen-Deutsch-INI**](https://github.com/rjcncpt/StarCitizen-Deutsch-INI): 독일어 언어 옵션을 지원하는 커뮤니티 유지 관리 `global.ini` 번역입니다.
- **[스타 시티즌 유저 한국어 프로젝트](https://sc.galaxyhub.kr)**(Shatagon, MGM Star Fleet, Falco Rescue 길드) — 한국어 현지화를 만들고 유지하는 커뮤니티 팀입니다. 라이선스상 이 파일을 재배포할 수 없어 Smart Citizen에는 번들로 포함되어 있지 않습니다. 대신 **언어 파일 매핑**(설정 탭)을 통해 자신이 직접 받은 `global.ini` 파일을 가리키도록 지정하세요.

## 주요 기능

### 🎯 핵심 기능
- **불러오기 및 편집**: Star Citizen 설치 폴더에서 `global.ini`를 불러오고 직관적인 테이블 보기에서 텍스트를 사용자 지정하세요
- **다중 채널 지원**: LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW는 각각 독립된 `user.ini`, 캐시, 백업, DataForge 추출을 가집니다. 재시작 없이 설정 탭에서 채널을 전환하세요
- **다국어 지원**: 설정 탭에서 앱과 게임 텍스트를 영어, 프랑스어, 스페인어, 브라질 포르투갈어, 일본어, 중국어, 이탈리아어, 독일어, 한국어(직접 가져온 파일 사용) 간에 전환하세요. 영어가 아닌 언어는 커뮤니티 번역 `global.ini`를 영어 기본 텍스트 위에 겹쳐 적용하며, 번역되지 않은 부분은 영어로 대체됩니다. 커뮤니티 번역이 도착함에 따라 더 많은 언어가 제공될 예정입니다(`languages/TRANSLATIONS.md` 참조)
- **임무 계약**: 전용 임무 카테고리에서 임무 계약 및 브리핑 텍스트를 편집하세요
- **스마트 필터링**: 텍스트를 검색하고, 카테고리(함선, 함선 부품, 임무, 장비, 교역품, 저널, 기타) 또는 수정 상태로 필터링하세요
- **열별 필터**: 각 열 제목 아래의 필터 상자에 직접 입력하여 세밀하게 검색하세요
- **실시간 미리보기 패널**: 선택한 행의 텍스트에서 게임의 현지화 토큰(줄바꿈, EM3/EM4 강조, 임무 자리표시자)을 스타일이 적용된 HTML로 렌더링하여, 텍스트가 게임 내에서 대략 어떻게 보일지 알 수 있습니다
- **편집기 옆 패널**: 도구 모음에서 켜고 끌 수 있고, 드래그로 크기 조절 및 도킹 해제가 가능한 화면으로, 밑줄/강조 버튼과 실시간 패널 간 동기화와 함께 긴 값(저널 항목, 임무 브리핑, 함선 설명)을 편집할 수 있습니다
- **안전한 적용**: 적용은 먼저 타임스탬프가 찍힌 자동 백업을 만든 후 `global.ini`에 기록하고, 출력을 기본 키 세트와 비교해 검증하며, 불일치가 있으면 자동으로 되돌립니다
- **백업 복원**: 채널당 최대 5개의 백업 버전을 유지하며, 클릭 한 번으로 언제든지 변경 사항을 되돌릴 수 있습니다
- **현지화 지우기**: 저장된 재정의 내용을 잃지 않고 게임을 원본 텍스트로 되돌립니다
- **INI 가져오기**: 기존 INI 파일을 가져와 내장 충돌 대화 상자로 키별로 충돌을 해결하세요
- **간단 모드와 고급 모드**: 버튼 두 개짜리 간단한 화면(한 버튼은 저장된 설정으로 강화를 적용하고, 다른 버튼은 고급 모드로 전환)으로 열거나, 직접 편집하고 싶을 때 언제든지 전체 고급 UI(테이블, 필터, 강화, 설정)를 사용하세요. 설치 시 기본값을 선택하고 앱 안에서 언제든지 전환할 수 있습니다
- **자주 묻는 질문 탭**: 어떤 파일이 변경되는지, 정지 위험, Windows의 미확인 앱 경고, 변경 사항을 되돌리는 방법 등 가장 많이 받는 질문을 앱 안에서 바로 답합니다
- **유연한 창과 열**: 창을 원하는 크기로 조절하세요. 각 탭은 컨트롤을 압축하거나 자르는 대신 자체 내용을 스크롤합니다. 텍스트 편집기의 열은 드래그로 크기 조절이 가능하며(구분선을 더블클릭하면 내용에 맞춤), 열 너비와 창 레이아웃은 재시작 후에도 유지됩니다. **더 보기 → 창 비율 재설정**으로 기본값을 복원할 수 있습니다
- **가이드 튜토리얼**: 각 버전을 처음 실행할 때 새 사용자를 작업 흐름으로 안내하는 코치마크 투어입니다. 튜토리얼 버튼으로 언제든지 다시 볼 수 있습니다

### 🔄 데이터 소스 및 지속성
- **Data.p4k에서 소싱**: 모든 기본 현지화 및 DataForge 엔터티 데이터는 설치된 `Data.p4k`에서 직접 압축 해제됩니다. 다운로드도, 커뮤니티 미러도 없이 항상 실제 게임 버전과 동기화됩니다
- **지속적인 편집**: 사용자 지정 내용은 매 세션마다 자동으로 저장되고 다시 로드됩니다
- **원활한 마이그레이션**: Star Citizen이 업데이트되면 패치된 `Data.p4k`에서 다시 추출하세요. 저장된 편집 내용이 새 기본 텍스트에 자동으로 다시 적용됩니다
- **깔끔한 UI**: 필터, 인라인 편집, 키보드 단축키, 현대적인 인터페이스를 갖춘 고성능 테이블 보기

### 📊 강화
- **함선 통계**: SCM 속도, 수소/퀀텀 연료, 화물 용량, 전체 무기 구성, 방어구 배율(물리/에너지/왜곡/열)이 함선 설명에 추가됩니다
- **부품 통계**: 실드, 냉각기, 발전기, 퀀텀 드라이브, 레이더에 대한 실드 HP, 전력 소모, 냉각 속도, 재생 속도 등의 통계가 기본적으로 `[MIL-S2-A]` 스타일의 이름 태그와 함께 표시됩니다(태그 빌더에서 완전히 사용자 지정 가능)
- **무기 통계**: S1부터 캐피탈급까지 함선 총과 터렛의 DPS, 발사 속도, 사거리, 피해량입니다. 함선 무기는 `[E-S2]` 스타일의 피해+크기 태그를, 미사일은 `[IR-S1] Arrester III`를, 폭탄은 `[S5] 500SCB Cluster`를 받습니다
- **임무 주석**: 제목에 `[BP]` / `[BP?]` 설계도 보상 태그가 추가되고, 설명에는 구조화된 *임무 세부 정보*, *잠재적 설계도*, *아이템 보상* 블록이 추가됩니다. 평판 등급 줄은 일반적인 번호 대신 실제 등급 이름(Rookie, Jr. Contractor 등)을 표시합니다. 임무 경험치는 그것이 어느 평판 트랙에 반영되는지 표시하며, Battaglia 스캔/채굴 제목은 대상 광석별 임무 세부 정보 "자원 신호" 상세 내역과 짝을 이루는 `[RS ####]` 자원 신호 태그를 가지며, 임무 추적기를 포함해 게임이 해당 이름을 표시하는 모든 곳에 나타나는 광석 이름 주석도 함께 표시됩니다(둘 다 기본적으로 켜져 있는 독립된 두 옵션)
- **저널 교차 참조**: 채굴 개론서 항목은 제작 교차 참조와 각 광석의 기본 자원 신호를 얻습니다. 제작에 사용되는 상품은 사용자 지정 가능한 `[CF]` 이름 태그와 그것을 필요로 하는 모든 설계도 목록을 얻습니다
- **의료 소모품 효과**: 기본 CureLife 펜(MedPen, OxyPen, AdrenaPen 등)에 쉬운 효과 설명 줄이 추가되어, 설명이 배경 설정뿐 아니라 그 펜이 실제로 무엇을 하는지 알려줍니다
- **함선 즐겨찾기**: 함선을 즐겨찾기로 표시하면 게임 내 ASOP 터미널 맨 위에 정렬되도록 설정 가능한 접두사(기본값 `*`)가 앞에 붙습니다
- **태그 빌더**: 부품, 미사일, 함선 무기, 상품의 괄호 태그를 사용자 지정합니다. 요소 순서를 바꾸고, 약자 길이(M / MIL / Military)를 변경하고, 구분 기호와 괄호를 선택하고, 태그를 이름 앞이 아니라 뒤에 배치할 수 있습니다. 부품에는 선택적인 유형 요소(실드, 냉각기 등)가 있고, 상품에는 제작 재료가 무엇에 쓰이는지 보여주는 용도 요소가 있습니다
- **임무 제목**: 운송 제목을 경로로 시작하게 합니다(예: `Area18 > Lorville`). 배치, 화살표, 구분 기호, 위치 세부 정보를 사용자 지정할 수 있으며, 선택적인 기본 제목 축약과 실시간 미리보기도 제공됩니다
- **통계 위/아래**: 통계 블록이 설명의 위에 위치할지 아래에 위치할지 선택하세요
- **설계도 추적기**: 이미 보유한 제작 설계도를 표시하는 전용 탭입니다. 사용 가능/보유 사이에서 항목을 이동하고, 임무/유형/등급/크기/품급으로 필터링하며, 보유한 항목은 임무 설계도 목록에서 파란색 `[보유 중]` 태그를 받습니다. **보유 설계도를 위해 로그 스캔**은 Star Citizen 로그 파일에서 소유 여부를 자동으로 채우며, 마지막 스캔 이후 새로 발견된 것만 가져옵니다. **보유 설계도 내보내기/가져오기**는 보유 목록을 PC 간에 옮깁니다(JSON 또는 CSV; 가져오기는 항상 추가만 하며, scmdb.net 내보내기도 사용 가능)
- **임무 레이블**: 섹션 제목(임무 세부 정보, 잠재적 설계도 등), 경험치 레이블, 제목에 사용되는 강조 태그의 이름을 바꾸세요
- **선언적 CIG 데이터 오류 패치**: 패치 시스템이 추출 시점에 알려진 DataForge 오류에 대한 수정을 적용하여, CIG를 기다리지 않고도 게임 내 텍스트가 올바르게 표시됩니다
- **선택적 카테고리**: 강화 탭에서 각 강화 카테고리를 독립적으로 활성화하거나 비활성화하세요

- **자동 백업**: 게임에 변경 사항을 적용하기 전에 타임스탬프가 찍힌 백업을 생성합니다(채널당 최대 5개)
- **레지스트리 지속성**: 모든 경로와 환경설정은 Windows 레지스트리에 안전하게 저장됩니다
- **사용자 지정 데이터 저장소**: 사용자 지정 편집 내용은 세션 간 안전한 지속성을 위해 `<데이터 폴더>\<채널>\` 아래에 저장됩니다(기본값 `Documents\Smart Citizen`, Star Citizen 채널마다 독립된 하위 트리)
- **설정 백업**: 전체 설정(환경설정, 태그 구성, 모든 채널의 텍스트 재정의)을 하나의 작은 zip으로 내보낸 후, 새 PC나 휴대용 버전을 새로 압축 해제한 후 가져오세요. 가져오기는 먼저 현재 파일의 스냅샷을 저장하므로 되돌릴 수 있습니다
- **앱 내 로그 뷰어**: 레벨 필터, 자동 스크롤, 버그 보고를 위한 내보내기 버튼이 있는 실시간 애플리케이션 로그
- **자동 업데이트**: Smart Citizen은 시작 시 GitHub 릴리스를 확인하고 릴리스 노트를 앱 내에 표시합니다. 클릭 한 번(과 Windows 권한 요청)으로 업데이트를 다운로드, 설치하고 앱을 다시 엽니다

## 빠른 시작

1. **최초 실행**: 앱이 Star Citizen 설치를 자동으로 감지합니다(**설정** 탭에서 편집 가능)
2. **추출**: 설정 탭에서 **Data.p4k에서 추출**을 클릭해 설치된 게임에서 기본 현지화 + DataForge 엔터티 데이터를 압축 해제하세요. 추출이 완료되면 텍스트가 테이블에 자동으로 로드됩니다
3. **텍스트 편집**: 검색 및 필터 도구를 사용한 다음, 텍스트를 사용자 지정하려면 아무 사용자 지정 값 셀을 더블클릭하세요
4. **적용**: **강화 적용**을 클릭하세요. 변경 사항이 저장되고 자동 백업과 함께 적용됩니다
5. **강화(선택 사항)**: 강화 탭을 열어 함선, 부품, 무기, 임무 보상에 대한 통계 오버레이를 활성화하세요
6. **게임 업데이트 후**: Data.p4k에서 추출을 다시 실행하세요. 편집 내용이 자동으로 다시 적용됩니다
