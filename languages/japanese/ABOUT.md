# Smart Citizen

*Smarter Strings for Star Citizen*

## このプロジェクトについて

**Smart Citizen** は、Star Citizen プレイヤーがゲームのローカライズ文字列をカスタマイズするための、強力で使いやすいツールです。完全な永続化、自動バックアップ、そしてゲームアップデートへのシームレスな対応とともに、ローカライズの変更を読み込み、編集し、適用できます。

ゲームコミュニティに価値あるツールを届けることに専念する、一人開発スタジオ **Osiris DevWorks** が開発しています。

## Osiris DevWorks の約束

Osiris DevWorks のツールはすべて、**完全無料**であるか、または**無料プラン**を備えています。私たちは、有料の壁や強制的なサブスクリプションなしにゲーマーへ価値を提供することを信条としています。

## 主な機能

### 🎯 コア機能
- **読み込みと編集**: Star Citizen のインストールから `global.ini` を読み込み、直感的なテーブルビューで文字列をカスタマイズ
- **マルチチャンネル対応**: LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW がそれぞれ独立した `user.ini`、キャッシュ、バックアップ、DataForge 抽出を持ち、再起動せずに Config タブからチャンネルを切り替え可能
- **多言語対応**: Config タブから、アプリとゲーム文字列を英語、フランス語、スペイン語、ブラジルポルトガル語、日本語、中国語（簡体字）、イタリア語、ドイツ語、繁体字中国語の間で切り替え。英語以外の言語は、コミュニティ翻訳の `global.ini` を英語ベースの上に重ね、未翻訳の部分は英語にフォールバックします。コミュニティの翻訳が届くにつれて、より多くの言語が公開されます（`languages/TRANSLATIONS.md` を参照）
- **ミッションコントラクト**: 専用の Missions カテゴリーから、ミッションのコントラクトとブリーフィングのテキストを編集
- **スマートフィルタリング**: 文字列を検索し、カテゴリー（艦船、艦船アイテム、ミッション、装備、商品、ジャーナル、その他）や変更ステータスでフィルタリング
- **列ごとのフィルター**: 各列ヘッダーの下のフィルターボックスに直接入力して、きめ細かく検索
- **ライブプレビューペイン**: サイドのプレビューが、選択した行のテキストをゲームのロックトークン（改行、EM3/EM4 の強調、ミッションのプレースホルダー）をスタイル付き HTML に変換して表示し、文字列がゲーム内でおおよそどう見えるかを確認できます
- **エディターサイドパネル**: ツールバーで切り替え可能、ドラッグでサイズ変更可能、ドッキング解除可能なキャンバスで、長い値（ジャーナルエントリー、ミッションブリーフィング、艦船説明）を下線／ハイライトボタンとペイン間ライブ同期とともに編集
- **安全な適用**: 「適用」は、まず自動でタイムスタンプ付きバックアップを取ってから `global.ini` に書き込み、出力を標準キーセットと照合して検証し、不一致があれば自動的にロールバックします
- **バックアップの復元**: チャンネルごとに最大 5 つのバックアップバージョンを保持 — ワンクリックでいつでも変更を元に戻せます
- **ローカライズのクリア**: 保存したオーバーライドを失うことなく、ゲームをバニラのテキストに戻します
- **INI のインポート**: 既存の INI ファイルをインポートし、組み込みの競合ダイアログでキーごとに競合を解決
- **シンプル & 詳細モード**: 2 ボタンのシンプル画面（片方は保存済み設定で拡張を適用、もう片方は詳細モードに切り替え）で開くか、手動編集したいときはいつでも完全な詳細 UI（テーブル、フィルター、Enhancements、Config）を使用。デフォルトはインストール時に選び、アプリ内で切り替え可能
- **FAQ タブ**: よく寄せられる質問に、アプリ内で直接回答 — どのファイルが変更されるか、BAN のリスク、Windows の「認識されないアプリ」警告、変更を元に戻す方法
- **柔軟なウィンドウと列**: ウィンドウを自由なサイズに変更できます — 各タブが自身の内容をスクロールするため、コントロールが押しつぶされたり見切れたりしません。文字列エディターの列はドラッグで幅を変更でき（区切り線をダブルクリックすると内容に合わせて調整）、列幅とウィンドウのレイアウトは次回起動時にも保持されます。**その他 → ウィンドウの比率をリセット** で既定値に戻せます
- **ガイド付きチュートリアル**: コーチマークのツアーが、各バージョンの初回起動時に新規ユーザーをワークフローに沿って案内 — チュートリアルボタンからいつでも再生可能

### 🔄 データの取得と永続化
- **Data.p4k から取得**: すべての標準ローカライズと DataForge エンティティデータは、インストール済みの `Data.p4k` から直接展開されます — ダウンロードもコミュニティミラーも不要で、常に実際のゲームバージョンと同期しています
- **永続的な編集**: カスタマイズはすべてのセッションで自動的に保存・再読み込みされます
- **シームレスな移行**: Star Citizen がアップデートされたら、パッチ適用後の `Data.p4k` から再抽出してください — 保存した編集は新しいベース文字列に自動的に再適用されます
- **クリーンな UI**: フィルター、インライン編集、キーボードショートカット、モダンなインターフェースを備えた高性能テーブルビュー

### 📊 拡張
- **艦船ステータス**: SCM 速度、水素／クアンタム燃料、貨物容量、完全な武器ロードアウト、アーマー倍率（物理／エネルギー／ディストーション／サーマル）を艦船説明に追加
- **コンポーネントステータス**: シールド HP、消費電力、冷却速度、リジェネなど、シールド・クーラー・パワープラント・クアンタムドライブ・レーダーのステータスを、デフォルトで `[MIL-S2-A]` 形式の名称タグ付きで表示（タグビルダーで完全にカスタマイズ可能）
- **武器ステータス**: S1 からキャピタルまでの艦船砲・タレットの DPS、発射レート、射程、ダメージ。艦船武器には `[E-S2]` 形式のダメージ＋サイズタグ、ミサイルには `[IR-S1] Arrester III`、爆弾には `[S5] 500SCB Cluster` が付きます
- **ミッション注釈**: タイトルに `[BP]` / `[BP?]` のブループリント報酬タグ、さらに説明内に構造化された *MISSION DETAILS*、*POTENTIAL BLUEPRINTS*、*ITEM REWARDS* のブロック。評判ティアの行は、汎用的な番号ではなく実際のランク名（Rookie、Jr. Contractor など）を表示します。ミッション XP はそれが寄与する評判トラックを示し、Battaglia のスキャン／採掘タイトルには `[RS ####]` のリソースシグネチャタグが付きます。加えて、対象となる鉱石ごとの内訳を示す MISSION DETAILS の「Resource Signatures」と、ミッショントラッカーを含めゲームがその名前を表示するすべての場所に現れる鉱石名への注釈が付きます（2 つの独立した切り替えで、どちらもデフォルトで有効）
- **ジャーナルの相互参照**: 採掘コンペンディウムのエントリーにはクラフトの相互参照と各鉱石のベースリソースシグネチャが付き、クラフトに使われる商品にはカスタマイズ可能な `[CF]` 名称タグと、それを必要とするすべてのブループリントのリストが付きます
- **医療消耗品の効果**: 基本の CureLife ペン（MedPen、OxyPen、AdrenaPen など）に平易な効果の行が付き、説明がそのロアだけでなくペンの働きを伝えます
- **艦船のお気に入り**: 艦船にスターを付けると、設定可能なプレフィックス（デフォルトは `*`）が先頭に追加され、ゲーム内 ASOP ターミナルの上位にお気に入りが並びます
- **タグビルダー**: コンポーネント、ミサイル、艦船武器、商品の角括弧付きタグをカスタマイズ — 要素を並べ替え、省略の長さを変更（M / MIL / Military）、区切り文字と括弧を選び、あるいはタグを名前の前ではなく後ろに配置。コンポーネントには任意のタイプ要素（Shield、Cooler など）、商品にはそのクラフト材料が何に使われるかを示す用途要素があります
- **ミッションタイトル**: 運送タイトルの先頭にルートを表示（例：`Area18 > Lorville`）— 配置、矢印、区切り文字、地点の詳細を設定でき、任意で標準タイトルの短縮も可能。ライブプレビュー付き
- **ステータスを上か下に**: ステータスブロックを説明の上部と下部のどちらに置くかを選択
- **ブループリントトラッカー**: すでに所有しているクラフトブループリントをマークする専用タブ。アイテムを Available と Owned の間で移動し、ミッション／タイプ／クラス／サイズ／グレードでフィルタリング。所有済みアイテムには、ミッションのブループリントリストで青い `[Owned]` タグが付きます。**ログから所有ブループリントをスキャン**は、Star Citizen のログファイルから所有状況を自動的に取り込み、前回のスキャン以降の新しいものだけをインポートします。**所有ブループリントのエクスポート / インポート**は、所有リストを PC 間で移動します（JSON または CSV。インポートは追加のみで、scmdb.net からのエクスポートも使えます）
- **ミッションラベル**: セクションヘッダー（MISSION DETAILS、POTENTIAL BLUEPRINTS など）、XP ラベル、ヘッダーに使う強調タグの名称を変更
- **宣言的な CIG データバグパッチ**: パッチシステムが、既知の DataForge バグへの修正を抽出時に適用するため、CIG を待たずにゲーム内テキストが正しく読めます
- **カテゴリーの選択**: Enhancements タブから、各拡張カテゴリーを個別に有効／無効化

### 🛡️ データ管理
- **自動バックアップ**: ゲームに変更を適用する前に、タイムスタンプ付きバックアップを作成（チャンネルごとに最大 5 つ）
- **レジストリでの永続化**: すべてのパスと設定を Windows レジストリに安全に保存
- **設定可能なデータ保存**: カスタム編集は `<データフォルダー>\<チャンネル>\`（デフォルトは `Documents\Smart Citizen`、Star Citizen チャンネルごとに独立したサブツリー）の下に保存され、セッションをまたいで安全に永続化されます
- **設定のバックアップ**: セットアップ全体（環境設定、タグ設定、すべてのチャンネルの文字列オーバーライド）を 1 つの小さな zip にエクスポートし、新しい PC で、または新しいポータブル版の展開後にインポートできます。インポートはまず現在のファイルをスナップショットするため、元に戻せます
- **アプリ内ログビューアー**: レベルフィルター、自動スクロール、バグ報告用のエクスポートボタンを備えたリアルタイムのアプリケーションログ
- **自動アップデーター**: Smart Citizen は起動時に GitHub Releases を確認し、リリースノートをアプリ内に表示します。ワンクリック（と Windows の許可プロンプト）で、アップデートをダウンロード・インストールし、アプリを再起動します

## クイックスタート

1. **初回起動**: アプリが Star Citizen のインストールを自動検出（**Config** タブで編集可能）
2. **抽出**: Config タブの **Data.p4k から抽出** をクリックして、インストール済みのゲームから標準ローカライズ + DataForge エンティティデータを展開 — 抽出が完了すると、文字列は自動的にテーブルに読み込まれます
3. **文字列の編集**: 検索・フィルターツールを使い、任意の Custom Value セルをダブルクリックしてテキストをカスタマイズ
4. **適用**: **拡張を適用** をクリック — 変更が自動バックアップとともに保存・適用されます
5. **拡張（任意）**: Enhancements タブを開き、艦船、コンポーネント、武器、ミッション報酬のステータスオーバーレイを有効化
6. **ゲームアップデート後**: Data.p4k からの抽出を再実行 — 編集は自動的に再適用されます
