# よくある質問

よく聞かれる質問への簡単な回答です。ここに載っていない質問がある場合は、フッターの **フィードバック** リンクをクリックして、Discord でお尋ねください。

## Smart Citizen が行った変更を元に戻すにはどうすればいいですか？

簡単です、いつでも可能です。Smart Citizen はゲームの元のファイルを直接編集することはないため、バニラ状態に戻すのはワンクリックです。

- **ツールバー → その他 → ローカライズをクリア** で、Smart Citizen が書き込んだカスタム `global.ini` を削除します。ゲームはすぐに内蔵のテキストに戻ります。編集内容が失われることはなく、アプリ内に保存されたままなので、いつでも再適用できます。
- 全部消すのではなく、1つ前のバージョンに戻したい場合は？ **ツールバー → その他 → バックアップを復元** で、タイムスタンプ付きのバックアップにゲームファイルを戻します（Smart Citizen は直近5個のバックアップを保持し、適用のたびに新しいものを作成します）。

個人の編集内容は、ゲームとは別に、Smart Citizen のデータフォルダー内の `user.ini` に保存されているため、ゲームファイルをクリアしても影響を受けません。

## Smart Citizen を使うとBANされますか？

Smart Citizen はローカライズのテキスト（ゲームが表示する文言）のみを編集し、ゲームのロジックには一切触れず、優位性を与えることもなく、CIG のサーバーと通信することもありません。私たちの変更は**問題ない**はずです。

オプションの **Smart Citizen Overlay**（オーバーレイタブ）も、同じくゲームに手を加えない方式で動作します。ゲームの上に通常のウィンドウを描画し、スクリーンショットツールと同じように画面のピクセルを読み取り、ゲームの `Game.log` ファイルを読み込みます。ゲームへのインジェクションやフックは一切行わず、ゲームのプロセスを開いたりメモリを読み取ったりすることもなく、キーボードやマウスの入力を送ることもありません。CIG はこのようなオーバーレイについて何も表明していないため、下記と同じく自己責任でのご利用となります。

CIG はコミュニティによるローカライズを公式に支持しています。彼らの [Community Localization Update](https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/star-citizen-community-localization-update) の投稿では、プレイヤーによる翻訳への公式なサポートが示されており、これは Smart Citizen が行うようなローカライズ編集を明示的に許可していると私たちは理解しています。

知名度の高いストリーマーも同様のローカライズプロジェクトを公然と運営しており、誰も中止を求められていません。

とはいえ、Smart Citizen の使用は自己責任でお願いします。私たちの変更は問題ないはずですが、あなた自身が行うことについては、発生しうる損害の責任はあなたとその関係者にあります。ある変更が適切かどうか分からない場合は、見た目だけの変更にとどめ、バックアップを取っておいてください。

## Smart Citizen はどのファイルを変更しますか？

たった1つだけで、**拡張を適用** をクリックしたときだけです。

- `StarCitizen\<チャンネル>\data\Localization\<言語>\global.ini` — 選択したチャンネル（LIVE、PTU など）と言語のゲームローカライズファイルです。Smart Citizen はまず既存のファイルをバックアップしてから、マージ結果を書き込みます。
- また、ゲームが正しいローカライズを読み込めるように、`user.cfg` の `g_language` が設定されていることも確認します。ゲームのインストール内の他の部分には一切触れません。

Smart Citizen が自身の使用のために生成するもの（ソースキャッシュ、拡張ファイル、バックアップ、`user.ini`）はすべて、ゲーム内ではなく Smart Citizen のデータフォルダーに保存されます。

## なぜ Windows はこのアプリを「認識されていません」と表示するのですか？

Smart Citizen がまだコード署名されていないためです。Windows の SmartScreen や Smart App Control は、署名証明書が登録されていない発行元からの新しいアプリを、たとえ完全に安全であってもフラグ表示します。これは「これまで見たことがない」という警告であり、「これは危険だ」という警告ではありません。

実行するには：SmartScreen のプロンプトで **詳細情報 → 実行** をクリックしてください。Smart App Control が完全にブロックしている場合は、そのプロンプトからアプリを許可するか、一時的に Smart App Control をオフにしてインストールし、その後再度オンに戻してください。

コード署名は今後の計画に含まれており、実装されればこの警告は表示されなくなります。それまでは、本物のビルドであることを確認するため、公式の GitHub リリースからのみ Smart Citizen をダウンロードしてください。
