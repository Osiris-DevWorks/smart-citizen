# 常見問題

關於大家最常問的問題的快速解答。如果這裡沒有你想要的答案，請點選頁尾的 **反饋** 連結，到 Discord 上問我們。

## 如何撤銷智慧公民所做的更改？

非常簡單，而且隨時可以進行。智慧公民從不直接修改遊戲的原始檔案，所以恢復到原版只需一鍵：

- **工具欄 → 更多 → 清除本地化** 會刪除智慧公民寫入的自定義 `global.ini`。遊戲會立即回退到內建文字。你的編輯內容不會丟失，它們仍儲存在應用中，你可以隨時重新應用。
- 如果你只想回退一個版本而不是全部撤銷，**工具欄 → 更多 → 恢復備份** 可將遊戲檔案回滾到帶時間戳的備份（智慧公民保留最近 5 個備份，每次點選“應用”都會建立一個新的）。

你的個人編輯內容儲存在智慧公民資料資料夾中的 `user.ini` 裡，與遊戲本身分開存放，因此清除遊戲檔案永遠不會影響到它們。

## 使用智慧公民會被封號嗎？

智慧公民只編輯本地化文字（遊戲顯示給你看的文字），不涉及遊戲邏輯，不提供任何優勢，也不與 CIG 的伺服器通訊。我們的修改**應該**是安全的。

CIG 曾公開支援社群本地化。他們釋出的[社群本地化更新](https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/star-citizen-community-localization-update)帖子明確表示官方支援玩家制作的翻譯，我們理解這明確允許了智慧公民所做的這類本地化編輯。

知名度很高的主播也在公開進行類似的本地化專案，沒有一個被要求停止。

話雖如此：你使用智慧公民的方式風險自負。我們的更改應該沒問題，但你自己所做的任何操作，由你及相關人員對可能產生的損失承擔責任。如果你不確定某項更改是否合適，請只做外觀上的修改，並保留備份。

## 智慧公民會修改哪些檔案？

只有一個，而且僅在你點選 **應用增強內容** 時：

- `StarCitizen\<頻道>\data\Localization\<語言>\global.ini` —— 你所選頻道（LIVE、PTU 等）和語言對應的遊戲本地化檔案。智慧公民會先備份現有檔案，然後寫入合併後的結果。
- 它還會確保你的 `user.cfg` 中設定了 `g_language`，以便遊戲載入正確的本地化檔案。你遊戲安裝目錄中的其他任何內容都不會被觸碰。

智慧公民自身使用的所有生成內容（源快取、增強內容檔案、備份、你的 `user.ini`）都存放在你的智慧公民資料資料夾中，而不是遊戲目錄裡。

## 為什麼 Windows 提示這個應用不受信任？

因為智慧公民尚未進行程式碼簽名。Windows SmartScreen 和 Smart App Control 會對任何沒有簽名證書記錄的新應用發出警告，即使它完全安全也是如此。這只是一句“我們之前沒見過這個”的提示，而不是“這很危險”。

執行方法：在 SmartScreen 提示中點選 **更多資訊 → 仍要執行**。如果 Smart App Control 直接將其攔截，你可以在其提示中允許該應用，或者臨時關閉 Smart App Control，安裝後再重新開啟。

程式碼簽名已列入我們的路線圖，屆時這個警告將會消失。在此之前，請只從我們官方的 GitHub 釋出頁面下載智慧公民，以確保你拿到的是正版構建。
