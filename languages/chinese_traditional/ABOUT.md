# 智慧公民

*為星際公民打造更智慧的字串*

## 關於本專案

**智慧公民** 是一款強大、易用的工具，供《星際公民》玩家自定義遊戲的本地化字串。載入、編輯並應用本地化更改，具備完整的持久化儲存、自動備份，並能無縫支援遊戲更新。

由 **Osiris DevWorks** 開發——一家致力於為遊戲社群打造有價值工具的個人開發工作室。

## 主要功能

### 🎯 核心功能
- **載入與編輯**：從你的《星際公民》安裝目錄載入 `global.ini`，在直觀的表格檢視中自定義字串
- **多頻道支援**：LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW 各自擁有獨立的 `user.ini`、快取、備份和 DataForge 提取內容——無需重啟即可在配置標籤頁中切換頻道
- **多語言支援**：在配置標籤頁中於英語、法語、西班牙語、巴西葡萄牙語、日語、中文（簡體）、義大利語、德語和繁體中文之間切換應用介面和遊戲字串。非英語語言會將社群翻譯的 `global.ini` 疊加在英文基礎內容之上，任何未翻譯的內容都會回退到英文。隨著社群翻譯的完善，將會開放更多語言（見 `languages/TRANSLATIONS.md`）
- **任務合同**：在專門的“任務”分類中編輯任務合同和簡報文字
- **智慧篩選**：按分類（飛船、飛船物品、任務、裝備、商品、日誌、其他）或修改狀態搜尋、篩選字串
- **逐列篩選**：直接在每個列標題下方的篩選框中輸入，實現精細搜尋
- **實時預覽面板**：側邊預覽會將所選行文字中的遊戲本地化標記（換行、EM3/EM4 強調、任務佔位符）渲染為帶樣式的 HTML，讓你大致瞭解該字串在遊戲中的顯示效果
- **編輯器側邊面板**：可透過工具欄切換、可拖拽調整大小、可取消停靠的畫布，用於編輯較長的值（日誌條目、任務簡報、飛船描述），帶下劃線/高亮按鈕及實時跨面板同步
- **安全應用**：應用時會先自動建立帶時間戳的 `global.ini` 備份，再對照官方鍵集校驗輸出內容，任何不匹配都會自動回滾
- **恢復備份**：每個頻道最多保留 5 個備份版本——一鍵即可隨時還原更改
- **清除本地化**：在不丟失已儲存覆蓋項的情況下，將遊戲恢復為原版文字
- **匯入 INI**：匯入現有 INI 檔案，透過內建的衝突對話方塊逐鍵解決衝突
- **簡易與高階模式**：預設開啟雙按鈕的簡易介面（一個按鈕用你儲存的設定應用增強內容，另一個切換到高階模式），或使用完整的高階介面（表格、篩選、增強內容、配置）隨時手動編輯。安裝時選擇預設模式，應用內可隨時切換
- **常見問題標籤頁**：在應用內直接解答我們最常被問到的問題——會修改哪些檔案、封號風險、Windows 的未識別應用警告，以及如何撤銷更改
- **靈活的視窗與列寬**：可將視窗調整為任意大小——每個標籤頁都會滾動自身內容，而不會擠壓或裁剪控制元件。字串編輯器的列可拖動調整寬度（雙擊分隔線可自動適應內容），列寬與視窗布局會在下次啟動時保留，並可透過 **更多 → 重置視窗比例** 恢復預設設定
- **引導教程**：以標註式引導帶新使用者完成首次啟動每個版本時的工作流程——可隨時透過教程按鈕重新播放

### 🔄 資料來源與持久化
- **來源於 Data.p4k**：所有官方本地化和 DataForge 實體資料都直接從你已安裝的 `Data.p4k` 中解包——無需下載，無社群映象，始終與你實際的遊戲版本同步
- **持久化編輯**：你的自定義內容會在每次會話中自動儲存並重新載入
- **無縫遷移**：《星際公民》更新後，從更新後的 `Data.p4k` 重新提取——你儲存的編輯會自動重新應用到新的基礎字串上
- **簡潔介面**：高效能的表格檢視，帶篩選、行內編輯、鍵盤快捷鍵和現代化介面

### 📊 增強內容
- **飛船資料**：SCM 速度、氫燃料/量子燃料、貨艙容量、完整武器配裝，以及護甲倍率（物理/能量/畸變/熱能）附加到飛船描述中
- **元件資料**：護盾生命值、耗電量、冷卻速率、回覆速度等資料，適用於護盾、冷卻器、發電機、量子引擎和雷達——預設帶 `[MIL-S2-A]` 風格的名稱標籤（可在標籤生成器中完全自定義）
- **武器資料**：從 S1 到主力艦級別的飛船炮和炮塔的 DPS、射速、射程和傷害。飛船武器帶有 `[E-S2]` 風格的傷害+尺寸標籤，導彈為 `[IR-S1] Arrester III`，炸彈為 `[S5] 500SCB Cluster`
- **任務註釋**：標題上的 `[BP]` / `[BP?]` 藍圖獎勵標籤，以及描述中結構化的 *任務詳情*、*潛在藍圖* 和 *物品獎勵* 區塊。聲望等級行顯示實際的陣營等級名稱（新手、初級承包商等），而非通用編號。任務經驗會標明其所屬的聲望陣營，巴塔利亞的掃描/採礦任務標題帶有 `[RS ####]` 資源訊號標籤，並配有任務詳情中按目標礦石列出的“資源訊號”明細，以及在遊戲顯示礦石名稱的所有位置（包括任務追蹤器）都會出現的礦石名稱註釋（兩個獨立開關，均預設開啟）
- **日誌交叉引用**：採礦彙編條目獲得製作交叉引用及每種礦石的基礎資源訊號；用於製作的商品獲得可自定義的 `[CF]` 名稱標籤，以及需要該商品的所有藍圖列表
- **醫療消耗品效果**：基礎 CureLife 醫療筆（MedPen、OxyPen、AdrenaPen 等）獲得通俗易懂的效果說明，讓描述告訴你這支筆實際的作用，而不只是背景設定
- **飛船收藏**：為飛船加星標，即可新增可自定義的字首（預設 `*`），使收藏項排在遊戲內 ASOP 終端列表的最前面
- **標籤生成器**：自定義元件、導彈、飛船武器和商品上括號內的標籤——重新排序元素、更改縮寫長度（M / MIL / Military）、選擇分隔符和括號，或將標籤放在名稱之後而不是之前。元件有可選的“型別”元素（護盾、冷卻器等）；商品有“用途”元素，顯示其製作材料的用途
- **任務標題**：以路線開頭顯示貨運任務標題（例如 `Area18 > Lorville`）——可自定義位置、箭頭、分隔符和地點詳情，並可選縮短官方標題，帶實時預覽
- **資料統計置於上方或下方**：選擇資料統計塊位於描述的頂部還是底部
- **藍圖追蹤器**：專門用於標記你已擁有的製作藍圖的標籤頁。在“可用”與“已擁有”之間移動物品，按任務/型別/等級/尺寸/品級篩選，已擁有物品會在任務藍圖列表中獲得藍色 `[已擁有]` 標籤。**掃描日誌以查詢已擁有藍圖** 會根據你的《星際公民》日誌檔案自動填充已擁有狀態，只匯入自上次掃描以來的新內容，**匯出/匯入已擁有藍圖** 則可在不同電腦之間轉移已擁有列表（JSON 或 CSV；匯入只會新增內容，scmdb.net 的匯出檔案同樣適用）
- **任務標籤**：重新命名區塊標題（任務詳情、潛在藍圖等）、經驗標籤，以及用於標題的強調標籤
- **宣告式 CIG 資料錯誤補丁**：一個補丁系統會在提取時應用對已知 DataForge 錯誤的修正，讓遊戲內文字正確顯示，無需等待 CIG 修復
- **分類可選**：在增強內容標籤頁中獨立啟用或禁用每個增強內容分類

### 🛡️ 資料管理
- **自動備份**：在向遊戲應用更改前建立帶時間戳的備份（每個頻道最多 5 個）
- **登錄檔持久化**：所有路徑和偏好設定都安全儲存在 Windows 登錄檔中
- **可配置的資料儲存**：你的自定義編輯內容儲存在 `<資料資料夾>\<頻道>\` 下（預設 `文件\Smart Citizen`，每個《星際公民》頻道擁有獨立的子目錄），確保跨會話安全持久化
- **設定備份**：將你的整套配置（偏好設定、標籤配置及每個頻道的字串覆蓋項）匯出到一個小壓縮包，然後在新電腦上或全新解壓便攜版後匯入。匯入會先為你當前的檔案建立快照，因此是可逆的
- **應用內日誌檢視器**：實時應用日誌，帶級別篩選、自動滾動，以及用於提交 Bug 報告的匯出按鈕
- **自動更新**：智慧公民在啟動時檢查 GitHub 釋出頁面，並在應用內顯示更新說明；只需一次點選（以及一次 Windows 授權提示）即可下載更新、安裝並重新開啟應用

## 快速上手

1. **首次啟動**：應用會自動檢測你的《星際公民》安裝位置（可在 **配置** 標籤頁中編輯）
2. **提取**：在配置標籤頁中點選 **從 Data.p4k 提取**，從你已安裝的遊戲中解包官方本地化內容及 DataForge 實體資料——提取完成後字串會自動載入到表格中
3. **編輯字串**：使用搜尋和篩選工具，然後雙擊任意自定義值單元格來自定義文字
4. **應用**：點選 **應用增強內容**——你的更改會被儲存並應用，同時自動建立備份
5. **增強內容（可選）**：開啟增強內容標籤頁，為飛船、元件、武器和任務獎勵啟用資料統計疊加層
6. **遊戲更新後**：重新執行“從 Data.p4k 提取”——你的編輯會自動重新應用
