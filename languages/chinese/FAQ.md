# 常见问题

关于大家最常问的问题的快速解答。如果这里没有你想要的答案，请点击页脚的 **反馈** 链接，到 Discord 上问我们。

## 如何撤销智慧公民所做的更改？

非常简单，而且随时可以进行。智慧公民从不直接修改游戏的原始文件，所以恢复到原版只需一键：

- **工具栏 → 更多 → 清除本地化** 会删除智慧公民写入的自定义 `global.ini`。游戏会立即回退到内置文本。你的编辑内容不会丢失，它们仍保存在应用中，你可以随时重新应用。
- 如果你只想回退一个版本而不是全部撤销，**工具栏 → 更多 → 恢复备份** 可将游戏文件回滚到带时间戳的备份（智慧公民保留最近 5 个备份，每次点击“应用”都会创建一个新的）。

你的个人编辑内容保存在智慧公民数据文件夹中的 `user.ini` 里，与游戏本身分开存放，因此清除游戏文件永远不会影响到它们。

## 使用智慧公民会被封号吗？

智慧公民只编辑本地化文本（游戏显示给你看的文字），不涉及游戏逻辑，不提供任何优势，也不与 CIG 的服务器通信。我们的修改**应该**是安全的。

可选的 **Smart Citizen 叠加层**（叠加层标签页）同样以不干预游戏的方式工作。它在游戏上方绘制普通窗口，像截图工具一样读取屏幕像素，并读取游戏的 `Game.log` 文件。它从不注入或挂钩游戏，从不打开游戏进程或读取其内存，也从不发送键盘或鼠标输入。CIG 尚未就此类叠加层发表过任何说法，因此下文同样的“风险自负”说明也适用于它。

CIG 曾公开支持社区本地化。他们发布的[社区本地化更新](https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/star-citizen-community-localization-update)帖子明确表示官方支持玩家制作的翻译，我们理解这明确允许了智慧公民所做的这类本地化编辑。

知名度很高的主播也在公开进行类似的本地化项目，没有一个被要求停止。

话虽如此：你使用智慧公民的方式风险自负。我们的更改应该没问题，但你自己所做的任何操作，由你及相关人员对可能产生的损失承担责任。如果你不确定某项更改是否合适，请只做外观上的修改，并保留备份。

## 智慧公民会修改哪些文件？

只有一个，而且仅在你点击 **应用增强内容** 时：

- `StarCitizen\<频道>\data\Localization\<语言>\global.ini` —— 你所选频道（LIVE、PTU 等）和语言对应的游戏本地化文件。智慧公民会先备份现有文件，然后写入合并后的结果。
- 它还会确保你的 `user.cfg` 中设置了 `g_language`，以便游戏加载正确的本地化文件。你游戏安装目录中的其他任何内容都不会被触碰。

智慧公民自身使用的所有生成内容（源缓存、增强内容文件、备份、你的 `user.ini`）都存放在你的智慧公民数据文件夹中，而不是游戏目录里。

## 为什么 Windows 提示这个应用不受信任？

因为智慧公民尚未进行代码签名。Windows SmartScreen 和 Smart App Control 会对任何没有签名证书记录的新应用发出警告，即使它完全安全也是如此。这只是一句“我们之前没见过这个”的提示，而不是“这很危险”。

运行方法：在 SmartScreen 提示中点击 **更多信息 → 仍要运行**。如果 Smart App Control 直接将其拦截，你可以在其提示中允许该应用，或者临时关闭 Smart App Control，安装后再重新打开。

代码签名已列入我们的路线图，届时这个警告将会消失。在此之前，请只从我们官方的 GitHub 发布页面下载智慧公民，以确保你拿到的是正版构建。
