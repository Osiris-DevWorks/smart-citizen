# 智慧公民

*为星际公民打造更智能的字符串*

## 关于本项目

**智慧公民** 是一款强大、易用的工具，供《星际公民》玩家自定义游戏的本地化字符串。加载、编辑并应用本地化更改，具备完整的持久化保存、自动备份，并能无缝支持游戏更新。

由 **Osiris DevWorks** 开发——一家致力于为游戏社区打造有价值工具的个人开发工作室。

## 主要功能

### 🎯 核心功能
- **加载与编辑**：从你的《星际公民》安装目录加载 `global.ini`，在直观的表格视图中自定义字符串
- **多频道支持**：LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW 各自拥有独立的 `user.ini`、缓存、备份和 DataForge 提取内容——无需重启即可在配置标签页中切换频道
- **多语言支持**：在配置标签页中于英语、法语、西班牙语、巴西葡萄牙语、日语、中文（简体）、意大利语、德语和繁体中文之间切换应用界面和游戏字符串。非英语语言会将社区翻译的 `global.ini` 叠加在英文基础内容之上，任何未翻译的内容都会回退到英文。随着社区翻译的完善，将会开放更多语言（见 `languages/TRANSLATIONS.md`）
- **任务合同**：在专门的“任务”分类中编辑任务合同和简报文本
- **智能筛选**：按分类（飞船、飞船物品、任务、装备、商品、日志、其他）或修改状态搜索、筛选字符串
- **逐列筛选**：直接在每个列标题下方的筛选框中输入，实现精细搜索
- **实时预览面板**：侧边预览会将所选行文本中的游戏本地化标记（换行、EM3/EM4 强调、任务占位符）渲染为带样式的 HTML，让你大致了解该字符串在游戏中的显示效果
- **编辑器侧边面板**：可通过工具栏切换、可拖拽调整大小、可取消停靠的画布，用于编辑较长的值（日志条目、任务简报、飞船描述），带下划线/高亮按钮及实时跨面板同步
- **安全应用**：应用时会先自动创建带时间戳的 `global.ini` 备份，再对照官方键集校验输出内容，任何不匹配都会自动回滚
- **恢复备份**：每个频道最多保留 5 个备份版本——一键即可随时还原更改
- **清除本地化**：在不丢失已保存覆盖项的情况下，将游戏恢复为原版文本
- **导入 INI**：导入现有 INI 文件，通过内置的冲突对话框逐键解决冲突
- **简易与高级模式**：默认打开双按钮的简易界面（一个按钮用你保存的设置应用增强内容，另一个切换到高级模式），或使用完整的高级界面（表格、筛选、增强内容、配置）随时手动编辑。安装时选择默认模式，应用内可随时切换
- **常见问题标签页**：在应用内直接解答我们最常被问到的问题——会修改哪些文件、封号风险、Windows 的未识别应用警告，以及如何撤销更改
- **灵活的窗口与列宽**：可将窗口调整为任意大小——每个标签页都会滚动自身内容，而不会挤压或裁剪控件。字符串编辑器的列可拖动调整宽度（双击分隔线可自动适应内容），列宽与窗口布局会在下次启动时保留，并可通过 **更多 → 重置窗口比例** 恢复默认设置
- **引导教程**：以标注式引导带新用户完成首次启动每个版本时的工作流程——可随时通过教程按钮重新播放

### 🔄 数据来源与持久化
- **来源于 Data.p4k**：所有官方本地化和 DataForge 实体数据都直接从你已安装的 `Data.p4k` 中解包——无需下载，无社区镜像，始终与你实际的游戏版本同步
- **持久化编辑**：你的自定义内容会在每次会话中自动保存并重新加载
- **无缝迁移**：《星际公民》更新后，从更新后的 `Data.p4k` 重新提取——你保存的编辑会自动重新应用到新的基础字符串上
- **简洁界面**：高性能的表格视图，带筛选、行内编辑、键盘快捷键和现代化界面

### 📊 增强内容
- **飞船数据**：SCM 速度、氢燃料/量子燃料、货舱容量、完整武器配装，以及护甲倍率（物理/能量/畸变/热能）附加到飞船描述中
- **组件数据**：护盾生命值、耗电量、冷却速率、回复速度等数据，适用于护盾、冷却器、发电机、量子引擎和雷达——默认带 `[MIL-S2-A]` 风格的名称标签（可在标签生成器中完全自定义）
- **武器数据**：从 S1 到主力舰级别的飞船炮和炮塔的 DPS、射速、射程和伤害。飞船武器带有 `[E-S2]` 风格的伤害+尺寸标签，导弹为 `[IR-S1] Arrester III`，炸弹为 `[S5] 500SCB Cluster`
- **任务注释**：标题上的 `[BP]` / `[BP?]` 蓝图奖励标签，以及描述中结构化的 *任务详情*、*潜在蓝图* 和 *物品奖励* 区块。声望等级行显示实际的阵营等级名称（新手、初级承包商等），而非通用编号。任务经验会标明其所属的声望阵营，巴塔利亚的扫描/采矿任务标题带有 `[RS ####]` 资源信号标签，并配有任务详情中按目标矿石列出的“资源信号”明细，以及在游戏显示矿石名称的所有位置（包括任务追踪器）都会出现的矿石名称注释（两个独立开关，均默认开启）
- **日志交叉引用**：采矿汇编条目获得制作交叉引用及每种矿石的基础资源信号；用于制作的商品获得可自定义的 `[CF]` 名称标签，以及需要该商品的所有蓝图列表
- **医疗消耗品效果**：基础 CureLife 医疗笔（MedPen、OxyPen、AdrenaPen 等）获得通俗易懂的效果说明，让描述告诉你这支笔实际的作用，而不只是背景设定
- **飞船收藏**：为飞船加星标，即可添加可自定义的前缀（默认 `*`），使收藏项排在游戏内 ASOP 终端列表的最前面
- **标签生成器**：自定义组件、导弹、飞船武器和商品上括号内的标签——重新排序元素、更改缩写长度（M / MIL / Military）、选择分隔符和括号，或将标签放在名称之后而不是之前。组件有可选的“类型”元素（护盾、冷却器等）；商品有“用途”元素，显示其制作材料的用途
- **任务标题**：以路线开头显示货运任务标题（例如 `Area18 > Lorville`）——可自定义位置、箭头、分隔符和地点详情，并可选缩短官方标题，带实时预览
- **数据统计置于上方或下方**：选择数据统计块位于描述的顶部还是底部
- **蓝图追踪器**：专门用于标记你已拥有的制作蓝图的标签页。在“可用”与“已拥有”之间移动物品，按任务/类型/等级/尺寸/品级筛选，已拥有物品会在任务蓝图列表中获得蓝色 `[已拥有]` 标签。**扫描日志以查找已拥有蓝图** 会根据你的《星际公民》日志文件自动填充已拥有状态，只导入自上次扫描以来的新内容，**导出/导入已拥有蓝图** 则可在不同电脑之间转移已拥有列表（JSON 或 CSV；导入只会添加内容，scmdb.net 的导出文件同样适用）
- **任务标签**：重命名区块标题（任务详情、潜在蓝图等）、经验标签，以及用于标题的强调标签
- **声明式 CIG 数据错误补丁**：一个补丁系统会在提取时应用对已知 DataForge 错误的修正，让游戏内文本正确显示，无需等待 CIG 修复
- **分类可选**：在增强内容标签页中独立启用或禁用每个增强内容分类

### 🎨 主题
- **默认**：深蓝色赛博主题，灵感来自《星际公民》的 mobiGlas 界面
- **浅色 / 深色**：经典界面主题

### 🛡️ 数据管理
- **自动备份**：在向游戏应用更改前创建带时间戳的备份（每个频道最多 5 个）
- **注册表持久化**：所有路径和偏好设置都安全保存在 Windows 注册表中
- **可配置的数据存储**：你的自定义编辑内容存储在 `<数据文件夹>\<频道>\` 下（默认 `文档\Smart Citizen`，每个《星际公民》频道拥有独立的子目录），确保跨会话安全持久化
- **设置备份**：将你的整套配置（偏好设置、标签配置及每个频道的字符串覆盖项）导出到一个小压缩包，然后在新电脑上或全新解压便携版后导入。导入会先为你当前的文件创建快照，因此是可逆的
- **应用内日志查看器**：实时应用日志，带级别筛选、自动滚动，以及用于提交 Bug 报告的导出按钮
- **自动更新**：智慧公民在启动时检查 GitHub 发布页面，并在应用内显示更新说明；只需一次点击（以及一次 Windows 授权提示）即可下载更新、安装并重新打开应用

## 快速上手

1. **首次启动**：应用会自动检测你的《星际公民》安装位置（可在 **配置** 标签页中编辑）
2. **提取**：在配置标签页中点击 **从 Data.p4k 提取**，从你已安装的游戏中解包官方本地化内容及 DataForge 实体数据——提取完成后字符串会自动加载到表格中
3. **编辑字符串**：使用搜索和筛选工具，然后双击任意自定义值单元格来自定义文本
4. **应用**：点击 **应用增强内容**——你的更改会被保存并应用，同时自动创建备份
5. **增强内容（可选）**：打开增强内容标签页，为飞船、组件、武器和任务奖励启用数据统计叠加层
6. **游戏更新后**：重新运行“从 Data.p4k 提取”——你的编辑会自动重新应用
