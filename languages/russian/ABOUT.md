# Smart Citizen

*Умные строки для Star Citizen*

## О проекте

**Smart Citizen** — мощный и удобный инструмент для игроков Star Citizen, позволяющий настраивать строки локализации игры. Загружайте, редактируйте и применяйте изменения локализации с полным сохранением данных, автоматическими резервными копиями и бесшовной поддержкой обновлений игры.

Разработан **Osiris DevWorks**, студией одного разработчика, посвящённой созданию полезных инструментов для игрового сообщества.

## Обещание Osiris DevWorks

Все инструменты Osiris DevWorks будут либо **полностью бесплатными**, либо иметь **бесплатный уровень доступа**. Мы верим в создание ценности для игроков без paywall или обязательных подписок.

## Основные возможности

### 🎯 Ключевые функции
- **Загрузка и редактирование**: загружайте `global.ini` из установки Star Citizen и настраивайте строки в интуитивно понятном виде таблицы
- **Поддержка нескольких каналов**: LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW — каждый получает свой изолированный `user.ini`, кэш, резервные копии и извлечение DataForge — переключайтесь между каналами на вкладке Config без перезапуска
- **Проверка места установки**: находит все установки Star Citizen на вашем ПК и читает журнал RSI Launcher, чтобы сообщить, какую из них игра действительно запускает, поэтому Apply никогда не пишет в копию, которую вы не запускаете
- **Поддержка нескольких языков**: переключайте строки приложения и игры между английским, французским, испанским, бразильским португальским, японским, китайским (упрощённым), итальянским, немецким, турецким, корейским (с принесением своего файла) и традиционным китайским на вкладке Config. Неанглийские языки накладывают переведённый сообществом `global.ini` на английскую основу с возвратом к английскому для непереведённого. Больше языков будет добавлено по мере появления переводов сообщества (см. `languages/TRANSLATIONS.md`)
- **Контракты миссий**: редактируйте текст контрактов и брифингов миссий из выделенной категории Missions
- **Умная фильтрация**: поиск строк, фильтрация по категориям (Ships, Ship Items, Missions, Gear, Commodities, Journal, Other) или статусу изменения
- **Фильтры по столбцам**: вводите текст непосредственно в поля фильтров под каждым заголовком столбца для детального поиска
- **Панель предварительного просмотра**: боковая панель отображает текст выбранной строки с игровыми токенами локализации (переносы строк, акценты EM3/EM4, плейсхолдеры миссий), преобразованными в стилизованный HTML, чтобы вы примерно видели, как строка будет выглядеть в игре
- **Боковая панель редактора**: включаемая с панели инструментов, изменяемая по размеру, открепляемая область для редактирования длинных значений (записи журнала, брифинги миссий, описания кораблей) с кнопками подчёркивания/выделения и живой синхронизацией между панелями
- **Безопасное применение**: Apply записывает в `global.ini` с автоматическим созданием резервной копии с временной меткой, валидирует результат по набору стандартных ключей и автоматически откатывает при несоответствии
- **Восстановление резервных копий**: храните до 5 резервных копий на канал — откатывайте изменения в любой момент одним кликом
- **Очистка локализации**: возвращайте игре стандартный текст без потери сохранённых переопределений
- **Импорт INI**: импортируйте существующий INI-файл и разрешайте конфликты по ключам с помощью встроенного диалога
- **Простой и расширенный режим**: открывайте двухкнопочный простой экран (одна кнопка применяет улучшения с сохранёнными настройками, другая переключает в расширенный) или используйте полный расширенный интерфейс (таблица, фильтры, Enhancements, Config), когда хотите редактировать вручную. Выбирайте режим по умолчанию при установке и переключайтесь между ними в приложении
- **Вкладка FAQ**: часто задаваемые вопросы, отвеченные прямо в приложении — какие файлы затрагиваются, риск бана, предупреждение Windows о нераспознанном приложении и как отменить изменения
- **Гибкое окно и столбцы**: изменяйте размер окна до любого — каждая вкладка прокручивает своё содержимое, а не сжимает или обрезает элементы управления. Столбцы String Editor изменяемы по размеру перетаскиванием (дважды щёлкните по разделителю для подгонки по содержимому), а ширина и компоновка окна сохраняются между запусками, с **More → Reset Window Proportions** для восстановления значений по умолчанию
- **Обзорный тур**: тур с метками-подсказками проводит новых пользователей по рабочему процессу при первом запуске каждой версии — повторяем в любой момент через кнопку Tutorial

### 🔄 Источники данных и сохранение
- **Источник — Data.p4k**: все стандартные строки локализации и данные сущностей DataForge распаковываются непосредственно из установленного `Data.p4k` — без загрузок, без зеркал сообщества, всегда синхронизированы с вашей фактической версией игры
- **Постоянные правки**: ваши настройки автоматически сохраняются и перезагружаются в каждой сессии
- **Бесшовная миграция**: при обновлении Star Citizen повторно извлекайте из обновлённого `Data.p4k` — ваши сохранённые правки автоматически применяются к новым базовым строкам
- **Чистый интерфейс**: высокопроизводительная таблица с фильтрами, редактированием на месте, горячими клавишами и современным интерфейсом

### 📊 Улучшения
- **Характеристики кораблей**: скорость SCM, водородное/квантовое топливо, грузоподъёмность, полные комплекты вооружения и множители брони (физическая / энергетическая / искажающая / тепловая), добавляемые к описаниям кораблей
- **Характеристики компонентов**: HP щитов, энергопотребление, скорость охлаждения, регенерация и аналогичные характеристики для щитов, охладителей, энергоблоков, квантовых двигателей и радаров — с тегами имён в стиле `[MIL-S2-A]` по умолчанию (полностью настраиваемые в Tag Builder)
- **Характеристики оружия**: DPS, скорострельность, дальность и урон корабельных пушек и турелей от S1 до капитальных. Корабельное оружие получает тег урона+размера в стиле `[E-S2]`, ракеты `[IR-S1] Arrester III`, а бомбы `[S5] 500SCB Cluster`
- **Аннотации миссий**: теги наград чертежей `[BP]` / `[BP?]` на заголовках, плюс структурированные блоки *MISSION DETAILS*, *POTENTIAL BLUEPRINTS* и *ITEM REWARDS* в описаниях. Строки уровней репутации показывают фактические названия рангов (Rookie, Jr. Contractor и т.д.) вместо общих номеров. Миссии XP указывают ветку репутации, а заголовки Battaglia scan/mine несут теги сигнатур ресурсов `[RS ####]`, дополненные разбивкой "Resource Signatures" в MISSION DETAILS для каждой целевой руды и аннотацией имени руды, отображаемой везде, где игра показывает это имя, включая трекер миссий (два независимых переключателя, оба включены по умолчанию)
- **Перекрёстные ссылки журнала**: записи Mining Compendium получают перекрёстные ссылки на крафт и базовую сигнатуру ресурса каждой руды; товары, используемые в крафте, получают настраиваемый тег имени `[CF]` и список каждого чертежа, который их требует
- **Эффекты медицинских расходников**: базовые ручки CureLife (MedPen, OxyPen, AdrenaPen и подобные) получают понятную строку эффекта, чтобы описание говорило, что ручка делает, а не просто её предысторию
- **Избранные корабли**: отмечайте корабль звёздочкой, чтобы добавить настраиваемый префикс (по умолчанию `*`) для сортировки избранных в верхнюю часть игрового терминала ASOP
- **Tag Builder**: настраивайте теги в скобках на компонентах, ракетах, корабельном оружии и товарах — изменяйте порядок элементов, длину аббревиатуры (M / MIL / Military), выбирайте разделители и скобки или размещайте тег после имени вместо перед ним. Компоненты имеют необязательный элемент Type (Shield, Cooler и т.д.); товары имеют элемент Usage, показывающий, на что идут их материалы крафта
- **Заголовки миссий**: добавляйте маршрут в заголовки перевозок (например, `Area18 > Lorville`) — настраиваемое размещение, стрелка, разделитель и детализация местоположения, плюс необязательное сокращение стандартных заголовков с живым предварительным просмотром
- **Характеристики сверху или снизу**: выбирайте, располагается ли блок характеристик в верхней или нижней части описания
- **Трекер чертежей**: выделенная вкладка для отметки уже имеющихся чертежей крафта. Перемещайте элементы между Available и Owned, фильтруйте по Mission / Type / Class / Size / Grade, а элементы в собственности получают синий тег `[Owned]` в списках чертежей миссий. **Scan Logs for Owned Blueprints** автоматически заполняет собственность из файлов журналов Star Citizen, импортируя только новое с момента последнего сканирования (или автоматически при запуске, когда включён **Auto-scan logs on startup**), а **Export / Import Owned Blueprints** перемещает список между компьютерами (JSON или CSV; импорт только добавляет, и экспорты scmdb.net тоже работают)
- **Метки миссий**: переименовывайте заголовки разделов (MISSION DETAILS, POTENTIAL BLUEPRINTS и т.д.), метку XP и тег акцента для заголовков
- **Декларативные патчи багов данных CIG**: система патчей применяет исправления к известным багам DataForge при извлечении, чтобы текст в игре читался корректно без ожидания CIG
- **Выборочные категории**: включайте или отключайте каждую категорию улучшений независимо на вкладке Enhancements

### 🛡️ Управление данными
- **Автоматические резервные копии**: резервные копии с временной меткой создаются перед применением изменений к игре (до 5 на канал)
- **Хранение в реестре**: все пути и настройки сохраняются в Windows Registry
- **Настраиваемое хранение данных**: ваши правки хранятся в `<data folder>\<channel>\` (по умолчанию `Documents\Smart Citizen`, одно изолированное поддерево на канал Star Citizen) для безопасного сохранения между сессиями
- **Резервное копирование настроек**: экспортируйте всю конфигурацию (настройки, конфигурации тегов и переопределения строк каждого канала) в один небольшой ZIP, затем импортируйте на новый ПК или после чистой распаковки портативной версии. Импорт сначала создает снимок текущих файлов, поэтому он обратим
- **Просмотрщик журнала в приложении**: журнал приложения в реальном времени с фильтром по уровнем, автопрокруткой и кнопкой Export для отчётов об ошибках
- **Автообновление**: Smart Citizen проверяет GitHub Releases при запуске и показывает описание изменений в приложении; один клик (плюс запрос разрешения Windows) загружает обновление, устанавливает его и открывает приложение заново

## Быстрый старт

1. **Первый запуск**: приложение автоматически определяет установку Star Citizen (редактируется на вкладке **Config**)
2. **Извлечение**: нажмите **Extract from Data.p4k** на вкладке Config для распаковки стандартной локализации и данных сущностей DataForge из установленной игры — строки загружаются в таблицу автоматически после завершения извлечения
3. **Редактирование строк**: используйте инструменты поиска и фильтров, затем дважды щёлкните по любой ячейке Custom Value для настройки текста
4. **Применение**: нажмите **Apply Enhancements** — ваши изменения сохраняются и применяются с автоматической резервной копией
5. **Улучшения (опционально)**: откройте вкладку Enhancements для включения наложения характеристик на корабли, компоненты, оружие и награды миссий
6. **После обновлений игры**: повторно запустите Extract from Data.p4k — ваши правки применяются автоматически
