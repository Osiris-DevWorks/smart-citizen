# Smart Citizen — Краткое руководство

## Первоначальная настройка

При запуске Smart Citizen загружает все ваши настройки из предыдущей сессии и проверяет установку Star Citizen — инсталлятор предварительно заполняет этот путь, но вы можете изменить его на вкладке **Настройки**. Все стандартные строки локализации и данные DataForge извлекаются **непосредственно из вашего установленного `Data.p4k`** (без загрузок, без зеркал сообщества), поэтому первое извлечение — обязательный шаг после установки или после любого обновления игры.

## Простой и расширенный режим

Smart Citizen открывается в одном из двух режимов, переключаться между которыми можно в любой момент.

- **Простой режим** — экран с двумя кнопками: одна кнопка, **Применить улучшения**, запускает всю цепочку с текущими настройками (извлечение, генерация, применение, с созданием резервной копии игрового файла перед записью); другая переключает в **расширенный режим**. Это быстрый путь, когда вам нужно только применить улучшения и не требуется редактирование строк вручную.
- **Расширенный режим** — полное приложение: таблица строк, фильтры, вкладка «Улучшения», вкладка «Настройки» и всё остальное, описанное в этом руководстве.

Выберите режим по умолчанию при установке или переключайтесь между ними прямо в приложении. Простой режим использует настройки, сохранённые в расширенном режиме.

## 1. Извлечение базовой локализации из Data.p4k

Откройте вкладку **Настройки** и нажмите **Извлечь из Data.p4k**. Это распакует стандартный `global.ini` плюс XML-файлы сущностей DataForge, используемые генератором улучшений — корабли, компоненты, оружие, миссии, чертежи и т.д.

После завершения извлечения полученный `base.ini` автоматически загружается в таблицу — с объединением файлов улучшений и ваших сохранённых переопределений из `user.ini`.

## 2. Редактирование строк локализации

- Дважды щёлкните по любой ячейке **Пользовательское значение** для редактирования текста.
- **Значение по умолчанию** — оригинальный текст из извлечённого `Data.p4k` файла `base.ini`.
- **Текущее значение** — фактическое значение до вашего переопределения (базовый + все импортированные слои INI).
- **Пользовательское значение** — ваше персональное редактирование. Сохраняется автоматически при каждом изменении и сохраняется в `<data folder>\<channel>\user.ini` (папка данных по умолчанию — `Documents\Smart Citizen`, и каждый канал Star Citizen — LIVE, PTU, EPTU, HOTFIX, TECH-PREVIEW — имеет свои изолированные переопределения).
- Столбец **Статус** отмечает каждую строку в зависимости от источника текущего значения:
  - **Изменённые** — вы явно отредактировали пользовательское значение.
  - **Улучшенные** — автоматически сгенерировано конвейером улучшений (наложение характеристик, теги чертежей и т.д.).
  - **Без изменений** — стандартный текст из `base.ini`.
  - **Новые** — ключ существует только в ваших переопределениях или в конвейере улучшений, но не в стандартном `base.ini`.
- **Изменение размера столбцов** — перетащите разделитель между заголовками столбцов или дважды щёлкните по разделителю, чтобы подогнать ширину столбца по самому широкому видимому содержимому. Ваши размеры запоминаются между запусками. Пока вы не измените что-то самостоятельно, Smart Citizen автоматически подгоняет столбцы под размер окна, поэтому новый установка всегда открывается корректно на любом экране. Чтобы вернуть автоматическую компоновку, используйте **Сбросить размеры окна** (см. ниже).

## 3. Панель предварительного просмотра

**Панель предварительного просмотра** в правом верхнем углу отображает отформатированный текст выбранной строки. Токены локализации игры преобразуются в стилизованный HTML, чтобы вы примерно видели, как ваша строка будет выглядеть в игре:

- `\n` → перенос строки
- `<EM3>...</EM3>` → подчёркнутый заголовок раздела
- `<EM4>...</EM4>` → жирное синее выделение (обычно значения характеристик)
- `~mission(Name)` → серый плейсхолдер `[Name]` (игра подставляет фактическое значение во время выполнения)

Панель остаётся видимой на всех вкладках и отражает последнюю выбранную строку в **Редакторе строк** — полезно для проверки форматирования длинного описания миссии или записи в журнале перед применением.

## 4. Категории

Используйте фильтр **Категория** для фокусировки на одной области:

- **Ships** — названия и описания кораблей (`vehicle_Name*`, `vehicle_Desc*`, а также моды Wikelo/Collector).
- **Ship Items** — щиты, энергоблоки, охладители, квантовые двигатели, прыжковые двигатели, корабельное оружие, ракеты, бомбы, турели.
- **Missions** — брифинги миссий, текст контрактов, описания наград.
- **Gear** — FPS-оружие, броня, шлемы, костюмы, оптика.
- **Commodities** — товары для торговли и материалы для крафта.
- **Journal** — записи в игровом журнале / стиле Galactapedia.
- **Other** — всё остальное.

## 5. Поиск и фильтрация

- Используйте **строку поиска** для поиска строк по ключу или содержимому текста.
- Комбинируйте с фильтрами **Категория** и **Статус** (Изменённые / Улучшенные / Без изменений / Новые).
- Установите **Скрыть без изменений**, чтобы сосредоточиться только на ваших правках.
- **Фильтры по столбцам** под каждым заголовком дополнительно сужают результаты в таблице.
- Нажмите на любой заголовок столбца для сортировки по нему. Нажмите на заголовок **★**, чтобы отсортировать избранные вверх.

## 6. Избранные корабли

- Нажмите на столбец **★** в любой строке корабля, чтобы добавить его в избранное. Только строка названия корабля может быть добавлена в избранное; строка описания того же корабля не имеет эквивалентного поведения в игре, поэтому столбцы звезды и порядка сортировки остаются пустыми.
- Корабли в избранном получают настраиваемый префикс перед названием, что помещает их в верхнюю часть игрового списка кораблей.
- Измените символ префикса на вкладке **Улучшения** (по умолчанию: `*`).
- Установите **Только названия кораблей** в строке поиска и фильтров, чтобы ограничить таблицу только строками названий кораблей и транспортных средств, скрыв описания кораблей и все остальные категории; сочетается с **★ Только избранные** для просмотра только тех строк, которые можно добавить в избранное.

## 7. Применение изменений к игре

Нажмите **Применить улучшения**, чтобы записать ваши правки в установку игры. Перед перезаписью создаётся резервная копия текущего `global.ini` с временной меткой в `<data folder>\<channel>\backups\`.

Цвет кнопки показывает статус: **красный** означает, что что-то изменилось с момента последнего применения (правка, перегенерация, смена языка или канала) и в игре этого ещё нет; **зелёный** означает, что игра уже соответствует загруженным данным, и кнопка остаётся неактивной, чтобы не переделывать работу. Тот же принцип красный/зелёный применяется к кнопкам **Сгенерировать улучшения** и **Сохранить изменения тегов** на вкладке «Улучшения». Если вы закроете приложение, пока кнопка «Применить улучшения» остаётся красной, Smart Citizen спросит, применить ли сейчас или выйти без применения, чтобы неприменённая работа не потерялась незаметно. Восстановление резервной копии или очистка локализации также делают кнопку красной, но закрытие после этого не спрашивает: вы выбрали это изменение, и красная кнопка — напоминание.

Smart Citizen также наносит небольшой водяной знак на строку версии лаунчера (`Frontend_PU_Version`), добавляя `\nLocalizations Enhanced with Smart Citizen v{VERSION}` на отдельной строке. Так вы можете подтвердить в игре, что ваш пакет локализации активен — посмотрите на метку версии в главном меню Star Citizen. Водяной знак перезаписывается при каждом применении, поэтому он не накапливается между версиями.

## 8. Восстановление резервной копии

Откройте меню **Ещё** на панели инструментов и выберите **Восстановить резервную копию**, чтобы вернуться к предыдущей версии. Smart Citizen хранит до **5 автоматических резервных копий** — самая старая удаляется при создании новых.

## 9. Очистка локализации

Откройте меню **Ещё** и выберите **Очистить локализацию**, чтобы удалить пользовательский `global.ini` из директории игры, вернув игре стандартный (vanilla) текст. Ваши сохранённые переопределения в `<data folder>\<channel>\user.ini` остаются нетронутыми и могут быть повторно применены в любой момент.

## 10. Импорт INI

Используйте **Импорт INI** на вкладке **Настройки** (также доступно в меню **Ещё** на панели инструментов), чтобы объединить существующий INI-файл с вашими переопределениями. Диалог разрешения конфликтов позволяет решать для каждого ключа: **оставить текущее**, **использовать импортированное**, **добавить в конец**, **добавить в начало** или указать **пользовательское** значение.

## 11. Экспорт Loc-Pack

Откройте меню **Ещё** и выберите **Экспорт INI…**, чтобы упаковать текущий применённый `global.ini` в один ZIP-файл — `SmartCitizen-LocPack-{channel}-{YYYYMMDD}.zip` — который любой другой пользователь может поместить в свою папку `StarCitizen\<channel>\data\Localization\english\`, чтобы использовать тот же пакет локализации без установки Smart Citizen. Полезно для обмена пресетами с друзьями или вашей организацией.

## 12. Сброс user.ini

Используйте **Сброс user.ini** на вкладке **Настройки**, чтобы удалить все ваши персональные правки для активного канала. Запрос подтверждения гарантирует, что это не случайный клик, а автоматическая резервная копия текущего `user.ini` создаётся в `<data folder>\<channel>\backups\` перед очисткой — поэтому сброс можно отменить, если вы передумаете.

## 13. Экспорт / импорт настроек

Используйте **Экспорт настроек…** и **Импорт настроек…** на вкладке **Настройки**, чтобы перенести всю вашу конфигурацию Smart Citizen между компьютерами или сделать резервную копию перед чистой установкой. Экспорт упаковывает настройки приложения и переопределения `user.ini` для каждого канала в один небольшой ZIP, включая путь установки Star Citizen; специфичные для компьютера пути и компоновка, которые не имеют смысла на другом ПК (папка данных, расположение кэша, геометрия окна, ширина столбцов «Редактора строк»), исключаются. Резервная копия фиксирует каждую настройку, включая те, которые остались по умолчанию, поэтому восстановление возвращает конфигурацию точно в прежнее состояние — настройка, изменённая *после* создания резервной копии, возвращается к значению по умолчанию, а не сохраняет более новое значение. Импорт накладывает эту резервную копию поверх текущих настроек и заменяет `user.ini` для каналов, которые она содержит — текущие файлы `user.ini` сначала сохраняются через **Восстановить user.ini**, поэтому импорт обратим. Путь Star Citizen сохраняется только если он всё ещё существует на ПК, на который вы импортируете; в противном случае Smart Citizen определяет его автоматически. Smart Citizen перезапускается после импорта для загрузки новых настроек, затем предлагает перегенерировать и применить улучшения.

## 14. После обновлений игры

Когда Star Citizen обновляется, ваши правки сохраняются в `<data folder>\<channel>\user.ini`. Повторно запустите **Извлечь из Data.p4k**, чтобы получить свежие стандартные строки из обновлённой игры — таблица перезагрузится автоматически, и ваши настройки применятся поверх.

## 15. Переключение языков

Выберите язык в выпадающем списке **Язык** на вкладке **Настройки** (рядом с «Канал»). Переключение изменяет как интерфейс приложения, так и игровые строки в таблице:

- **English** (по умолчанию) использует стандартные строки, извлечённые из вашего `Data.p4k`.
- **Другие языки** загружают переведённый сообществом `global.ini` для этого языка и накладывают его на английскую основу, поэтому любая строка, не покрытая переводом, возвращается к английскому варианту вместо отсутствия. Загрузка кэшируется по языкам; при повторном переключении используется кэш.
- **Улучшения остаются на английском.** Блоки характеристик, теги и детали миссий генерируются из игровых данных и сохраняют английскую форму поверх переведённого текста. Смешанная строка (например, название роли на французском внутри англоязычного блока характеристик) — ожидаемое поведение, а не ошибка.
- **Сопоставить файл языка** (вкладка «Настройки») позволяет указать для языка другой `global.ini` — URL (например, ваш форк перевода сообщества) или, через **Обзор...**, файл, уже имеющийся на диске. URL загружается и кэшируется; локальный файл копируется. В обоих случаях он имеет приоритет над встроенным по умолчанию. Для языков, перевод которых не может быть распространён (например, корейский), сопоставление локального файла — единственный вариант — сначала установите патч этого сообщества, **скопируйте его `global.ini` в место, отличное от установки Star Citizen** (сопоставление копии, которую Smart Citizen уже применяет там, приведёт к обратной связи собственного объединённого результата в качестве следующего «источника» и удвоению каждого улучшения), затем выберите эту копию через «Обзор...».
- **Русский и корейский используют один языковой слот игры.** В игре нет слота для русского языка, а корейский шрифт — единственный, который отображает кириллицу, поэтому русский применяется как корейский язык игры. Применение одного языка заменяет в игре файл другого, и в игре отображается только тот, который вы применили последним.
- Некоторые тексты интерфейса обновляются только после перезапуска приложения. Строки таблицы перезагружаются немедленно.

Применение записывает в соответствующую языковую папку в установке игры и устанавливает `g_language` в `user.cfg`, чтобы игра загружала правильный файл.

Хотите помочь с переводом? Статус перевода по языкам отслеживается в `languages/TRANSLATIONS.md` в репозитории, и мы предпочитаем опубликовать ваши слова, а не машинные. Свяжитесь с нами на Discord.

## 16. Обновления приложения

Smart Citizen проверяет наличие новой версии при каждом запуске. Когда она доступна, описание изменений отображается в прокручиваемом окне с двумя вариантами:

- **Обновить сейчас** загружает новый установщик, Windows запрашивает разрешение, и Smart Citizen закрывается, обновляется и открывается с новой версией. Ваши правки, резервные копии и настройки остаются нетронутыми.
- **Позже** оставляет вас на текущей версии; вопрос повторится при следующем запуске.

Вы также можете проверить вручную в любой момент через **Проверить обновления** на вкладке «Настройки». Портативные сборки показывают кнопку **Открыть страницу релиза** вместо этого, поскольку для них нет установщика: загрузите новый ZIP и распакуйте поверх старой папки.

## Вкладка «Улучшения»

- Переключайте наложение характеристик, которые добавляют числовые значения к описаниям — скорость SCM, HP щитов, DPS, грузоподъёмность, характеристики луча буровой установки (Fracture / Extraction), производительность ручных инструментов утилизации, пулы чертежей, XP миссий и многое другое. Миссии XP также указывают ветку репутации, которую они повышают (например: `750 XP (Hauling)`), контракты Battaglia scan/mine несут тег `[RS ####]` с базовой сигнатурой ресурса целевой руды, а журнал Mining Compendium перечисляет базовую RS каждой руды рядом с местами добычи.
- **Medical Consumables** — добавляет понятную строку эффекта к базовым ручкам CureLife (MedPen, OxyPen, AdrenaPen и подобным), чтобы описание говорило, что ручка делает, а не просто её предысторию.
- **Показать статистику выше описания** — перемещает блок характеристик в верхнюю часть описания вместо нижней, чтобы числа были первым, что вы видите в игре.
- **Показать ресурсные сигналы (RS) рядом с названиями руд** — добавляет базовую сигнатуру ресурса каждой добываемой руды к её отображаемому имени (например, "Aluminium (RS 4285)"), поэтому она отображается везде, где игра рендерит это имя, включая трекер миссий. Независимо от строки «Ресурсные сигналы» в полях деталей миссий ниже.
- Включайте или отключайте каждую категорию улучшений независимо.
- Настраивайте символ префикса избранных кораблей.
- **Blueprint ownership** перемещён на отдельную вкладку **Трекер чертежей**; см. следующий раздел.
- **Конструктор тегов** — настраивайте теги в скобках, размещаемые на именах компонентов, ракет, корабельного оружия, брони и товаров. Изменяйте порядок элементов с помощью ▲/▼, отключайте отдельные элементы, изменяйте длину аббревиатуры (`M` / `MIL` / `Military`), выбирайте разделитель (нет, дефис, пробел и т.д.) и скобки (квадратные, круглые, нет и т.д.), а также выбирайте, появляется ли тег перед или после имени. Компоненты также имеют необязательный элемент **Type** (Shield, Cooler, Power Plant и т.д.) — отключен по умолчанию. Товары имеют элементы **Label**, **Usage** (на что идут материалы крафта товара) и **Collection**, все отключены по умолчанию; включите нужные в конструкторе тегов. У **Armor** есть один элемент **Weight**, тоже отключённый по умолчанию: он помечает FPS-броню, шлемы и рюкзаки их весовым классом (`L` Light, `M` Medium, `H` Heavy, `S` Super Heavy, `U` Utility для защитных костюмов в стиле Novikov и Pembroke), а одежду — `C`, определяя их по игровым данным. Используйте **Редактировать сопоставление...**, чтобы изменить любую из этих букв. Теги на названиях брони записываются вместе с улучшениями **Gear**, поэтому для них нужно включить Gear. Если отмечено **Аннотировать компоненты и броню в описаниях миссий**, тот же тег появляется и на броне в списках POTENTIAL BLUEPRINTS описаний миссий; они берутся из улучшений **Missions**, поэтому показывают его даже с выключенным Gear. На вкладке Armor нет скобок None (только пробел): без скобок Трекер чертежей не смог бы сопоставить однословный тег брони с её предметом, поэтому этот вариант для брони недоступен. Нажмите **Сохранить изменения тегов** для сохранения и перегенерации. (**Сгенерировать улучшения** также сначала сохраняет любые незавершённые правки тегов, поэтому несохранённая настройка не потеряется при перегенерации.)
- **Mission Titles** (вкладка конструктора тегов) — добавляйте маршрут в заголовки миссий перевозки. Выберите размещение (Prepend, Append или Replace заголовка), стрелку маршрута (`>`, `->`, `to` или кодирующую форму `->-`/`->=`/`=>-`/`=>=`, показывающую один или несколько конечных пунктов с каждой стороны), разделитель заголовка и степень отображения местоположения (полный адрес по умолчанию; короткое имя может не отображаться на редких миссиях), с живым предварительным просмотром. Перевозка выглядит как `Area18 > Lorville - <original title>`, чтобы вы могли видеть задание на лету в списке контрактов, а многоостановочные перевозки перечисляют пункты выгрузки (`Area18 > Lorville, New Babbage`). Два независимых переключателя сокращают стандартный заголовок: **Сокращать оригинальные заголовки** применяет тщательно подобранные сокращения фраз (например, "Opportunity for Independent Cargo Hauler" → "Intro", "Local Shipment Route" → "Route", а также обработку Ling Family и префикса ранга), а **Сокращать размеры груза** сокращает размеры грузовых классов ("Extra Small" → "XS"). Отдельные чекбоксы дают более тонкий контроль — удалить "Cargo" или "Haul" полностью, убрать "Rank" или подчеркнуть "Direct" перевозки для акцента — чтобы маршрут и теги помещались даже в длинных заголовках. Чекбоксы **Общие теги** на той же странице показывают или скрывают теги только для заголовков: награда репутации, тег чертежа, `[ACE]`, тег Battaglia `[RS ####]` и название ветки репутации. Тег чертежа читается как `[BP]`, когда каждая версия миссии даёт чертёж, и `[BP?]`, когда это не гарантировано (только некоторые версии имеют его, или игровые данные отмечают награду как случайный выпад).
- **Метки миссий** — настраивайте заголовки разделов, используемые в блоках улучшений миссий (MISSION DETAILS, POTENTIAL BLUEPRINTS, ITEM REWARDS, BLUEPRINT DATA), метку XP, отображаемую на миссиях без конкретного ранга репутации (по умолчанию "Rep"), и тег акцента (EM3 = подчёркивание, EM4 = цвет), используемый для заголовков.
- **Поля деталей миссий** — показывайте или скрывайте каждую строку блока MISSION DETAILS отдельно (тип миссии, сложность, спавны, репутация, чертежи, пилот-ас и сигнатуры ресурсов), чтобы описания миссий содержали только те данные, которые вам важны. **Ресурсные сигналы** добавляет разбивку к контрактам Recco Battaglia scan/mining, перечисляющую полную прогрессию значения RS для каждой целевой руды, отдельно от тега миссии `[RS ####]` и аннотации имени руды выше.
- Нажмите **Сгенерировать улучшения** для извлечения данных DataForge из `Data.p4k` и пересборки INI-файлов улучшений. Декларативные патчи в `patches/` применяются идемпотентно при каждой перегенерации, поэтому известные баги данных CIG остаются исправленными без ожидания патча игры.

## Вкладка «Трекер чертежей»

Отслеживайте, какие чертежи крафта у вас уже есть, и видьте это отражённым в игре: предметы в собственности получают синий тег `[Owned]` в списках POTENTIAL BLUEPRINTS миссий, поэтому обзор контракта сразу показывает, что ещё нужно найти.

- **Два списка, одно перемещение.** Доступные чертежи слева, ваш набор справа. Выберите элементы и перемещайте их кнопками со стрелками. Набор в собственности сохраняется между перезапусками.
- **Быстрый поиск.** Строка поиска сужает оба списка, а фильтры **Миссия / Тип / Класс / Размер / Категория** сокращают доступный список по месту выпадения чертежа и типу предмета (Armor, Ammo, FPS Weapon, Ship Item и т.д.).
- **Наведите курсор на любой чертёж**, чтобы увидеть его тип, класс, размер и категорию, а также все миссии, которые могут его выпасть, по одной на строку.
- **Сканировать журналы на наличие чертежей** заполняет набор в собственности автоматически: он читает файлы журналов Star Citizen на предмет чертежей, полученных в игре, и отмечает их как имеющиеся. Импортируются только чертежи, полученные с момента последнего сканирования, поэтому повторный запуск в любой момент не требует много времени. Для сканирования необходим путь установки Star Citizen, указанный на вкладке «Настройки».
- **Стартовые чертежи.** У каждого игрока есть винтовка P4-AR и её магазин, пистолет S-38 и его магазин, а также четыре части костюма Field Recon Suit с первого фабрикатора. Игра никогда не записывает их получение в журнал, и ни одна миссия их не предлагает, поэтому они перечислены под меткой миссии *Default blueprint (every player has it)*, а ваше первое сканирование после обновления добавляет их в набор в собственности и сообщает о них, как о любых новых чертежах. Это происходит один раз: если вернуть один из них в «Доступные», он там и останется.
- **Какие серверы читает сканирование.** Сканирование всегда читает LIVE, а также HOTFIX, когда он установлен, независимо от выбранного канала на вкладке «Настройки». LIVE и HOTFIX работают на одном сервере и разделяют прогресс аккаунта, поэтому чертёж, заработанный на одном, появляется в журналах другого. PTU, EPTU и TECH-PREVIEW — отдельные тестовые серверы, которые сбрасываются чаще, поэтому они никогда не сканируются.
- **Повторное сканирование всех журналов (игнорировать последнее сканирование)** принудительно заставляет следующее сканирование перечитать каждую запись журнала с нуля вместо только нового с момента последнего сканирования. Используйте это, если ваш набор в собственности выглядит неправильно, а обычное сканирование не исправляет это. Галочка снимается после завершения сканирования.
- **Автосканирование журналов при запуске** запускает то же сканирование автоматически при каждом запуске Smart Citizen, чтобы ваш список «В наличии» оставался актуальным без ручного нажатия. Отключено по умолчанию. Отчёты приходят тихо через строку состояния вместо всплывающего окна, поэтому запуск, не нашедший ничего нового, остаётся незаметным.
- **Показывать всплывающее окно для новых чертежей, найденных автосканированием** возвращает обычное всплывающее окно с результатами (с расширяемым списком того, что было добавлено), когда автосканирование при запуске находит что-то новое, вместо просто сообщения в строке состояния. Отключено по умолчанию. Имеет значение только когда автосканирование также включено, и только когда оно действительно находит что-то новое.
- **Экспорт имеющихся чертежей… / Импорт имеющихся чертежей…** перемещают ваш список в собственности между компьютерами или позволяют поделиться с другом. Экспорт записывает всё, что у вас есть, в файл JSON или CSV; импорт считывает файл и добавляет всё найденное, никогда не удаляя уже имеющееся. Экспорты с scmdb.net тоже импортируются. В сводке импорта указано, сколько чертежей было новым, и перечислены имена в файле, которые Smart Citizen не отслеживает.
- **Применить теги имеющихся** повторно вплетает теги `[Owned]` в загруженные строки после изменения набора в собственности. Как и другие кнопки действий, она становится **красной**, когда ваш список «В наличии» содержит изменения, не отражённые в таблице, и **зелёной**, когда всё совпадает.
- Столбец **Имеющиеся** в таблице строк по-прежнему показывает звезду и сортирует имеющиеся первыми, но теперь доступен только для чтения; управление собственностью осуществляется с этой вкладки.

## Вкладка «Оверлей»

**Smart Citizen Overlay** рисует два небольших окна поверх Star Citizen: расшифровщик сканирования добычи и панель с поиском. Запускайте и останавливайте его кнопкой **Запустить оверлей** на этой вкладке или кнопкой **Оверлей** на панели инструментов. Запускайте игру в режиме «окно без рамки» на основном экране, иначе оверлей не сможет отображаться поверх неё. Оверлей только читает ваш экран и `Game.log`, а если вы задали горячую клавишу панели, следит за нажатиями клавиш только ради этого сочетания; саму игру он никогда не затрагивает.

- **Расшифровщик сканирования добычи** читает сигнатуру сканирования под радаром и показывает тип и количество залежей прямо под ней (например, `3 × Lindinium`). Метка меняется только после того, как одно и то же число прочитано дважды подряд, поэтому ошибка в одном кадре не мелькает. **Размер текста сканирования** делает метку мельче или крупнее. Круглое число вроде 12,000 может быть утилизацией или залежью на поверхности (добыча ROC или FPS); утилизация идёт первой, а остальные помечены как «только на поверхности», ведь в космосе это может быть только утилизация.
  - **Когда сканируется отслеживаемый минерал или утилизация**: выберите, как метка вас оповестит. **Свечение** и **Мигание** включены по умолчанию; можно добавить **Сменить цвет текста** (ярко-зелёный), **Крупнее текст** и **Звуковой сигнал**. Мигание и звук срабатывают, когда цель прочитана впервые, и не повторяются, пока она остаётся на экране.
- **Панель оверлея** размещает разделы с вкладками у края экрана. Нажмите на вкладку, чтобы открыть раздел, и ещё раз, чтобы закрыть. **Положение панели** выбирает одно из восьми мест (по умолчанию посередине справа). **Горячая клавиша панели** задаёт сочетание клавиш, которое открывает панель прямо из игры на последнем использованном разделе; повторное нажатие закрывает её. В игре, чтобы пользоваться в ней мышью, по-прежнему удерживайте F: Windows не даёт оверлею забрать мышь у Star Citizen. Star Citizen всё равно получает эти клавиши, поэтому выберите сочетание, которым вы не пользуетесь в игре. В нём должна быть Ctrl, Alt или Win, если это не клавиша F и не Pause. Кнопка **Очистить** удаляет горячую клавишу. Если его уже занимает другая программа, вкладка сообщит об этом.
  - **Чертежи**: ищите чертежи, смотрите, какие миссии дают их в награду, и отмечайте имеющиеся (тот же список, что и на вкладке «Трекер чертежей»).
  - **Минералы**: введите минерал, чтобы увидеть, где он встречается (по звёздным системам), или место, чтобы увидеть его минералы. Отметьте минерал или строку **Утилизация** внизу списка, чтобы отслеживать их: метка сканирования оповестит вас, когда сканирование их найдёт. Здесь же можно включить и выключить расшифровщик.
  - **Крафт**: введите минерал, чтобы увидеть, какие предметы его используют, или предмет, чтобы увидеть нужные ему минералы. Заполняется, когда вы генерируете улучшения с отмеченными **Commodities** или **Journal**.
  - У каждого раздела свой переключатель; выключение панели скрывает их все.
- **Отмечать новые чертежи как имеющиеся** следит за `Game.log`, пока работает оверлей, и отмечает полученные чертежи как имеющиеся. Как и сканирование журналов, читает только LIVE и HOTFIX: если на вкладке «Настройки» выбран PTU, EPTU или TECH-PREVIEW, функция не работает.
- **Сохранять образцы сканирования** сохраняет небольшое изображение каждой новой прочитанной сигнатуры в `logs\sco_samples`, чтобы ошибки распознавания можно было отправить. **Открыть папку образцов** открывает её. Включено по умолчанию; ничего не отправляется. За сеанс сохраняется не более 200 изображений, а в папке остаются только 1000 самых новых.

Если расшифровщик сталкивается с ошибкой, он останавливается, и об этом сообщает строка состояния. Остановите и снова запустите оверлей, чтобы попробовать ещё раз; подробности на вкладке «Журнал». В обзорном туре (кнопка **Обучение**) есть шаг для этой вкладки.

## Вкладка «Настройки»

- **Внешний вид** — выбор темы приложения (см. ниже) и **Размера шрифта** (маленький, средний или большой). Размер шрифта масштабирует текст вместе с элементами управления вокруг него, поэтому ничего не обрезается; Smart Citizen предложит перезапуск, потому что новый размер вступает в силу при запуске приложения.
- **Установка** — путь к вашей директории LIVE; определяется автоматически при установке, редактируется здесь. Выпадающий список **Канал** выбирает, какой канал приложение читает и записывает, а список **Язык** переключает строки приложения и игры (см. *Переключение языков* выше).
- **Проверить местоположение установки** — проверяет, что Smart Citizen указывает на копию Star Citizen, которую вы действительно запускаете. Если у вас несколько установок на ПК (перемещённая папка библиотеки, второй диск, остатки после переустановки), возможно приложение пишет в ту, которую RSI Launcher никогда не запускает: применение сообщает об успехе, но в игре ничего не меняется. Эта кнопка находит все возможные установки и сообщает, какую из них лаунчер действительно использует, читая собственный журнал лаунчера, а не угадывая по именам папок. Каждая найденная установка перечислена с доказательствами, и **Использовать эту установку** перенаправляет Smart Citizen на неё одним кликом. Если ваша установка находится в необычном месте, **Сканировать все диски** выполняет более медленный и глубокий поиск.
- **Данные Smart Citizen** — папка для `user.ini`, кэшированных базовых строк, сгенерированных INI улучшений и резервных копий. По умолчанию `Documents\Smart Citizen`; переместите с OneDrive, если очистка кэша занимает много времени.
- **Папка кэша DataForge** — где хранятся данные сущностей DataForge, извлечённые из `Data.p4k`, отдельно от папки данных выше. По умолчанию `%LOCALAPPDATA%\Smart Citizen`. Во время извлечения нужно до 4,5 ГБ свободного места (меньше, если кэш уже есть), и работа идёт рядом с этой папкой, а если папка находится на OneDrive, сетевом или съёмном диске или её путь очень длинный — в `%TEMP%`. Если места не хватает, извлечение останавливается до начала и сообщает, сколько нужно. Укажите другой диск через **Обзор...**, чтобы снять нагрузку с `C:`; изменение означает повторное извлечение.
- **Базовая локализация** — нажмите **Извлечь из Data.p4k** для распаковки стандартной локализации и данных сущностей DataForge непосредственно из вашей установленной игры. Это единственный источник базовых строк и данных улучшений.
- **Импорт INI** — объедините существующий INI-файл с вашими переопределениями через диалог разрешения конфликтов.
- **Сброс user.ini** — удалите все ваши персональные правки для активного канала. Запрашивает подтверждение и автоматически создаёт резервную копию текущего `user.ini` перед очисткой.
- **Восстановить user.ini** — откатите ваши персональные правки к более раннему снимку. Smart Citizen хранит ротационные резервные копии `user.ini` (до 5, создаются автоматически перед каждым изменением), поэтому если импорт или правка пошли не так, вы можете выбрать предыдущую версию и вернуть свои строки. Само восстановление обратимо: текущий файл сначала сохраняется как снимок.
- **Экспорт настроек… / Импорт настроек…** — создайте резервную копию всей вашей конфигурации (настройки плюс `user.ini` каждого канала) в один небольшой ZIP или восстановите её на новом ПК. См. *Экспорт / импорт настроек* выше.

## Вкладка «Журнал»

- Журнал приложения в реальном времени.

## Темы

Выберите тему в разделе **Настройки → Внешний вид**:

- **По умолчанию** — SCLE, тема в стиле киберпанк с тёмно-синим фоном, вдохновлённая интерфейсом mobiGlas в Star Citizen.
- **Светлая / Тёмная** — классические темы интерфейса.
- **ODW** — фирменная тема Osiris DevWorks, тёмно-синий уголь с античным золотом.

## Компоновка окна

Smart Citizen запоминает размер окна, компоновку закреплённого «Редактора строк» и ширину его столбцов между запусками. Каждая вкладка прокручивает своё содержимое, поэтому вы можете уменьшить окно до любого размера и получать ко всему доступ через прокрутку, а не сжатие или обрезку элементов управления.

Если компоновка оказалась неудобной — столбец сжат до полоски, или размер окна больше не подходит для вашего экрана — используйте **Ещё → Сбросить размеры окна**. Это восстанавливает размер окна, компоновку панелей и ширину столбцов к значениям по умолчанию. Ваши настройки, правки и данные локализации не затрагиваются.

## Обзорный тур

Нажмите кнопку **Обучение** на панели инструментов в любой момент, чтобы повторить обзорный тур — пошаговое руководство по основному рабочему процессу с экранными подсказками, указывающими на каждый элемент управления. Тур также запускается автоматически при первом запуске новой версии, поэтому новая установка никогда не начинается «холодной». Нажмите **Пропустить** в любой момент, чтобы пропустить его.

## Устранение неполадок

- **Таблица пуста** — Убедитесь, что **Извлечь из Data.p4k** завершено и перезагрузка после извлечения закончена, затем проверьте вкладку **Журнал** на наличие ошибок парсинга.
- **Улучшения пусты или отсутствуют элементы** — Запустите **Сгенерировать улучшения** с вкладки «Улучшения»; для этого необходим кэш DataForge (сначала нажмите **Извлечь из Data.p4k**, если ещё не сделали).
- **«Применить улучшения» не работает** — Проверьте путь установки Star Citizen на вкладке **Настройки** и убедитесь, что игра не запущена.
- **Применение сообщает об успехе, но игра выглядит неизменённой** — Возможно, у вас несколько установок Star Citizen, и Smart Citizen указывает на ту, которую вы не запускаете. Нажмите **Проверить местоположение установки** на вкладке **Настройки**: она называет установку, которую RSI Launcher действительно использует, и перенаправляет приложение одним кликом.
- **Извлечение сообщает, что Data.p4k заблокирован** — RSI Launcher загружает или проверяет обновление. Дождитесь завершения (или закройте лаунчер), затем снова нажмите **Извлечь из Data.p4k**.
- **Извлечение сообщает, что недостаточно свободного места** — Сообщение называет каждый диск, где не хватает места, сколько там свободно и сколько нужно извлечению. Освободите место на этом диске или выберите **Папку кэша DataForge** на диске с бо́льшим объёмом на **вкладке «Настройки»**. Текущий кэш DataForge остаётся без изменений.
- **Извлечение сообщает, что Windows не разрешила создать рабочую папку** — Сообщение называет папку. Проверьте права доступа к ней, разрешите Smart Citizen в «Контролируемом доступе к папкам» в Безопасности Windows или выберите другую **Папку кэша DataForge** на **вкладке «Настройки»**. Извлечение не началось, поэтому текущий кэш DataForge остаётся без изменений.
- **Windows не разрешила создать кэш DataForge, или Smart Citizen не удалось получить к нему доступ** — Сообщение называет папку. Проверьте права доступа к ней, разрешите Smart Citizen в «Контролируемом доступе к папкам» в Безопасности Windows, снова подключите диск, на котором она находится, или выберите другую **Папку кэша DataForge** на **вкладке «Настройки»**. Ничего не изменено: выбранная на **вкладке «Настройки»** папка не сохранена, а извлечение не началось. Пока этот диск отключён, вкладка «Улучшения» показывает кэш DataForge как ещё не извлечённый.
- **Извлечение сообщает, что папка кэша DataForge — это ссылка на другую папку** — Сообщение называет папку и то, куда она ведёт. Эта папка — соединение (junction) или символическая ссылка, а Smart Citizen ничего не удаляет через ссылку, поэтому извлечение не началось и текущий кэш DataForge остаётся без изменений. Выберите папку, в которую ведёт ссылка, как **Папку кэша DataForge** на **вкладке «Настройки»**, затем снова выполните извлечение.
- **Устаревшие данные после обновления игры** — Повторно запустите **Извлечь из Data.p4k**, затем перегенерируйте улучшения.

## Известные проблемы

Некоторые аномалии текста миссий происходят из данных самого Star Citizen — неправильная ссылка на loc-key в записи контракта или награда чертежа, данные которой не ссылаются на реальное отображаемое имя. Игра читает контракты и награды чертежей из собственного `Data.p4k` во время выполнения, поэтому Smart Citizen не может исправить это в источнике; он может только корректировать *текст*, который генерирует и применяет. Где это возможно, мы обходим это на уровне данных или генерации, чтобы результат в игре всё равно читался корректно.

- **Досье Jorrit — «Updated Power Usage Data» показывает текст Energy Anomaly** — CIG Issue Council [STARC-176797](https://issue-council.robertsspaceindustries.com/projects/STAR-CITIZEN/issues/STARC-176797). Контракт CIG `Hockrow_FacilityDelve_P2M4-Stanton4_Repeat` указывает свой параметр `Description` на `@Hockrow_FacilityDelve_P2M1_Repeat_desc` вместо собственного `P2M4_Repeat_desc`, поэтому в игре игроки видят текст P2M1's Energy Anomaly для миссии с названием "Power Usage Data". Smart Citizen обходит это двумя шагами, оба объявлены в `patches/contracts/contractgenerator/mercenary_guild/hockrowagency/hockrowagency_facilitydelve.patch.json`:
  1. Редактирование XML DataForge, чтобы наш генератор улучшений прикрепил правильный пул чертежей P2M4 (Corbel Smolder, Geist Rogue/Whiteout) к `P2M4_Repeat_desc` вместо сворачивания на P2M1.
  2. Обходной путь для loc-строки, добавляющий полное содержимое `P2M4_Repeat_desc` (его текст плюс собственный пул чертежей) к `P2M1_Repeat_desc`, разделённое маркированным разделителем. Поскольку игра читает ошибочный указатель и ищет `P2M1_Repeat_desc` для обоих контрактов, контракт P2M4 теперь отображает намеченное содержимое. Игроки P2M1 видят блок P2M4 как маркированное приложение после собственного описания — более шумно, но оба контракта теперь показывают правильный пул чертежей и правильный текст.

  Когда CIG исправит STARC-176797, весь файл патча можно удалить, и следующая перегенерация снова произведёт чистые разделённые описания.

- **Миссии дозаправки показывают искажённые названия сопел** (например, "Nozzle Fuelgiver Grin Nozzlefast" вместо "Norfield") в списке POTENTIAL BLUEPRINTS миссии. Награды чертежей топливных сопел не ссылаются на разрешимое имя сущности в данных CIG так, как это делают другие крафтовые предметы, поэтому наш генератор улучшений возвращался к деслагифицированной версии внутреннего имени файла вместо реального названия продукта. Исправлено для всех 8 известных вариантов топливных сопел (Marlin, Lindstrom, Bendix, Torrez, Ezra, Norfield, Harkin, RN-7s) через коррекцию известного имени в `scripts/generate_enhancements_ini.py`; повторно запустите **Сгенерировать улучшения** и **Применить улучшения**, чтобы подхватить исправление на уже просмотренных миссиях.
